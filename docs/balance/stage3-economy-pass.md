# 3단계 경제 측정 (장터·퀘스트 켬/끔)

날짜: 2026-11-21 · 브랜치 `stage3-econ` · 기준 문서: `docs/design/stage3-economy-draft.md`(이하 초안)

명령 (CSV는 `packages/sim/sim-out/stage3/`):

```
npm run sim -- --stage 3 --check grade6 --matrix on --defeat off --seeds 20
npm run sim -- --stage 3 --check grade6 --matrix on --defeat on --seeds 20
npm run sim -- --stage 3 --check grade6-lane --seeds 20
```

실제로는 설정 열 개를 `--config <이름>`으로 나눠 열 개 프로세스로 동시에 돌리고, `--report on`으로 CSV를 다시 읽어 표를 만들었다. 모든 설정이 20시드다(줄인 설정 없음). 한 판(6인 60라운드)은 약 10초, 설정 하나 20시드는 동시 실행에서 3~7.5분 걸렸다.

## 1. 넣은 것

### 규칙과 데이터 위치

## 2. 측정 방식

- 6인 매치, 시드 1~20, 여섯 자리 모두 같은 봇. 10틱마다 결정한다.
- 목표 봇(`target`): 히든이 아닌 6등급 하나를 시드로 골라 그 트리를 쫓는다. 장터·퀘스트 정책이 켜지면 트리 밖 유닛 중 공격력 상위 4기는 팔지 않는다(보스전용 전력).
- 목표 전환 봇(`switch`): 라운드가 바뀔 때마다, 아직 만들지 않은 일반 6등급 중 남은 1등급 환산 값이 지금 목표보다 4 이상 작은 것이 있으면 그쪽으로 바꾼다.
- 장터 정책: 보따리는 장날마다 두 번, 단지는 묵이 "다음 5등급 둘 + 최종 조합"에 모자랄 때만(초안 3장 기본 비교군). 둘 다 조합비 60냥(트리의 5등급을 가졌을 때)을 남긴다. 판이 꽉 차 있으면 보따리를 위해 한 기를 판다.
- 퀘스트 정책: 설화 목표 지정, 미션 입장(참가비를 내도 60냥이 남을 때), 수집 대상 조합. 길들이기는 히든 2기까지, 비용을 내도 목표에 쓸 묵·엽전이 남을 때만. 배달은 지게가 있는 고개가 다른 고개 목표에 모자라고 자기 트리에는 필요 없는 1~4등급을 보낸다.
- 설정: `base`(장터·퀘스트·설화·길들이기·배달 모두 끔), `market`(장터만), `quests4`(퀘스트 넷 + 설화), `full`(전부), `full-q2`(전부, 퀘스트는 시드마다 두 건 조합 여섯 가지를 돌아가며). 전투 드롭은 장터 스위치를, 그늘손은 길들이기 스위치를 따른다. 그래서 `base`에는 경제 수입이 없다.
- 패배 끔: 한도를 없애고 시간 초과 보스를 보상 없이 뺀다. 역신도 마감 틱 끝까지 살아 있으면 처치·보상 없이 판에서 빠지고(`noGate`), 그 관문은 못 잡은 것으로 센다. 탈락·관문 실패가 없으므로 살아 있는 자리를 모두 완주자로 센다. 패배 켬: 매치 결과에서 여섯 보스를 모두 잡은 자리만 완주자다.
- 6등급 수는 히든을 빼고 센다. "보유"는 60R 시작 틱의 보유 수다(마지막 강철이 직전).
- 묵 9/12개, 엽전 180/240냥 도달 라운드는 틱마다 늘어난 양만 더한 근사값이다. 같은 틱에 들어오고 나간 양은 상쇄되어 빠진다.
- 합격선(초안 8장): 완주자의 70% 이상이 3~4기, 미완성 5% 이하, 보유 수 중앙값 3~4기.

### 장터 끔/켬, 퀘스트 0/4

60R 시작 보유 수의 완주자 평균(패배 끔 / 패배 켬):

| 봇 | base | market | quests4 | full | full-q2 |
| --- | ---: | ---: | ---: | ---: | ---: |
| target | 1.32 / 1.92 | 1.48 / 2.00 | 1.35 / 1.94 | 1.74 / 2.04 | 1.77 / 2.05 |
| switch | 1.99 / 2.18 | 2.17 / 2.39 | 2.01 / 2.24 | 2.42 / 2.58 | 2.50 / 2.70 |

- **장터를 켜면** 평균 보유가 0.08~0.21기 늘고, 패배 켬 완주자가 늘어난다(target 12 → 14, switch 39 → 61). 묵 12개 도달은 switch에서 R58(패배 끔)·R50(패배 켬)에서 R40으로, target 패배 켬에서 R50에서 R40으로 당겨진다. target 패배 끔은 "없음"에서 R59가 된다. 패배 끔에서 봇은 장날마다 보따리 두 번(판당 12회)을 모두 샀고 단지는 판당 1.6~2.1개 샀다.
- **퀘스트 넷과 설화만 켜면** 보유는 거의 그대로다(+0.02~0.06). 패배 끔 네 건 설정에서 미션은 74~83%가 성공했고, 팀 의뢰는 85~100%가 받았다. 수집 도전 성공은 20~26%, 씨름은 판당 한 자리에만 오고 20판 중 9~16판에서 이겼다.
- **둘을 함께 켜면**(`full`) 효과가 더해지는 것보다 크다. switch는 3~4기 비율이 11% → 43%(패배 끔), 21% → 54%(패배 켬)가 된다. 배달은 자리당 판에 1.2~2.3회 성사했다.

이전 판의 이 표(넷째 패배 끔 188/200 · 88%)는 `noGate`가 관문 실패만 무시하고 역신을 남겨 둔 상태에서 잰 값이었다. 마감 뒤 잡은 판이 처치로 들어갔고(최대 약 272초), 생존자마다 15냥·묵 1개도 지급됐다. 지금은 마감 틱에 역신을 빼므로 패배 끔 CSV 20개를 다시 만들었다. 패배 켬 CSV는 바뀌지 않았다.

## 4. 초안 6장 예산과 비교

초안 예산은 묵 누적이 30R 10개, 40R 14⅙개, 60R 18⅙개다. 봇의 누적 묵(근사값)은 `full`에서 9개 도달이 R30, 12개 도달이 R38~R40이다. 예산보다 열 고개쯤 늦다. 장터를 끈 `base`·`quests4`에서는 12개에 아예 못 미치거나 R50~R58이다.

- 예산은 "열 고개당 개인 보스 1회"를 전제한다. 봇은 30R 이후 고개 보스를 자주 놓친다(패배 켬 완주자 비율 10~63%). 그래서 묵의 큰 몫(보스당 2개)이 빠진다.
- 엽전 180/240냥 누적은 모든 설정에서 R5/R7이다. 총수입 기준이라 판별력이 없다. 마지막 조합비가 실제로 모자란지는 이 열로 알 수 없다(후속 작업에 적었다).

## 5. 판정

**합격선을 넘은 설정은 없다.** 가장 가까운 것은 switch-full-q2 패배 켬으로, 완주자 76명 중 64%가 3~4기, 미완성 0%, 보유 중앙값 3기다(70% 기준에 6%p 모자람). 같은 봇의 패배 끔은 47%다. 목표 봇은 모든 설정에서 3~4기 비율이 17% 이하다. 초안은 "양쪽 봇 모두 중앙값 3~4기"를 요구하므로 목표 봇 쪽이 크게 모자란다.

## 6. 무엇이 막았나

- **트리의 5등급 재료.** 판 끝에 목표 레시피에서 빠진 재료 상위는 대부분 5등급이다. 패배 끔 `full`: target은 kkeul 22, dongwe 12, sil 12, jejuheobeok 12, maksabal 12; switch는 sil 30, kkeul 25, tteoksiru 14, kkwaenggwari 14, top 13 (완주자 120명 중 해당 재료가 빠진 수). 장터는 최고 3등급이라 5등급 하나(16값)를 채우는 데 보따리 대여섯 번이 든다.
- **보스 놓침.** 패배 켬에서 목표 봇은 완주자가 12~46명이다. 20R 강철이(21,000)에서 가장 많이 탈락하고 30·40R 보스(38,000·58,000)가 뒤를 잇는다. 보스전용 전력 4기를 남겨도 크게 바뀌지 않았다(target-full 46/120).
- **목표 고정.** 같은 경제에서 switch는 target보다 보유가 패배 끔에서 0.6~0.7기 많다. 재료에 맞춰 목표를 옮기는 것만으로 장터 전체보다 큰 차이가 난다. 사람 플레이어는 switch 쪽에 가깝다고 본다.
- **길들이기는 거의 쓰이지 않았다.** 자리당 판에 0.13~0.21회다. 봇은 10틱마다 HP를 보는데 15% 구간을 지나치는 경우가 많고, 묵을 목표용으로 남기는 조건 때문에 고개 보스 길들이기를 건너뛴다.
- **판매.** 판당 자리별 판매가 25~71기다. 목표 봇은 트리 밖 유닛을 계속 팔아 N(비퀘스트 원가)이 낮게 유지된다. 설화 한도 판정(3Q ≤ N)에 걸린 경우는 CSV에 따로 남기지 않았다.

### 남은 것

- **목표 봇의 3~4기 비율.** 이번 레버로는 목표 봇을 70%까지 올리면 전환 봇이 5기 이상으로 넘친다. 같은 경제에서 두 봇의 평균 보유 차이가 약 1.1기여서, 3~4기 폭(2기)에 둘을 함께 넣기 빠듯하다. 목표 봇은 무작위 목표를 바꾸지 않고 판당 100기 넘게 판다. 사람 플레이어는 전환 봇에 가깝다고 보고 이번 값을 골랐다. 목표 봇도 70%를 맞춰야 한다면 장터 수치가 아니라 목표에 맞는 재료를 고르게 하는 장치(예: 보따리에서 패 한 장을 고르기)나 합격선 해석을 다시 정해야 한다.
- **장터가 재료의 큰 몫을 맡는다.** 초안 6장은 보따리 12회 40값을 전제했는데, 지금 봇은 판당 42회쯤 사서 약 280값을 받는다. 직접 소환(약 117값)보다 크다. 5·6등급은 여전히 조합으로만 나오지만, 6장 예산표와 3장 "재료 보따리 12회" 문장은 새 값으로 고쳐야 한다. 보따리 지출은 판당 약 660냥에서 2,300냥으로 늘었고, 그만큼 강화에 덜 쓴다.
- **전투가 쉬워졌다.** 둘째·셋째 역신이 제한 시간의 35~48%에 잡힌다(초안 7장 기준 50~80%). 규칙대로라면 기본 체력을 올려야 한다. 고개 보스 체력(임시값)과 함께 다음 전투 측정에서 정한다.
- **묵이 남는다.** 60R에 5~8.5개가 남는다. 단지나 묵 보상을 줄일 여지가 있지만, 이번에는 합격선에 영향이 없어 두었다.
- 넷째 역신 체력 인하 제안(189,000)은 바뀐 경제에서 필요 없어서 보류했다.

## 10. 소환 쪽 공급 비교 (브랜치 `stage3-tune-summon`)

9장 안은 보따리가 재료의 주 공급원이 된다(봇이 받는 재료 약 280값 대 직접 소환 약 117값). 소환·조합 중심의 느낌에서 멀어질 수 있어, 보따리를 초안 값(장날마다 2회, [3,3,2])으로 되돌리고 소환 쪽 레버를 8시드(full-q2, 시드 1~8)로 비교했다. 값은 3단계 `balance`만 덮어쓰는 방식으로 넣어 1·2단계에는 영향이 없다.

## 11. 시너지 봇과 봇 계단 (브랜치 `stage3-synergy-bot`)

질문은 "지금 봇이 계열·방깍·마깍을 몰라서 6등급이 모자란 것 아닌가"였다. 그래서 공급을 키우는 대신 시너지를 아는 봇을 만들어, 초안 경제값(보따리 장날마다 2회, [3,3,2]) 그대로 다섯 봇을 같은 시드로 비교했다. 모두 `full-q2`, 시드 1~20, 패배 켬/끔이다.

```
npm run sim -- --stage 3 --check grade6 --matrix on --bot all --config synergy-full-q2 --defeat on --seeds 20
```

`--bot`은 `clumsy`·`normal`·`target`·`switch`·`synergy`·`all`(다섯 봇)·`both`(목표·전환)을 받는다. CSV에는 고개 보스 처치 시간 열(`boss10`~`boss60`, 못 잡으면 빈칸)을 더했다.

### 시너지 봇이 하는 일

전환 봇(`switch`)에 아래를 더했다. 판단은 모두 유닛 데이터(피해 유형, 계열, 효과)에서 읽고 유닛 id는 쓰지 않는다. 코드는 `packages/sim/src/stage3/synergy.ts`.

- **주력 계열.** 진영 유닛의 공격력을 물리·마법으로 나눠 더하고, 지금 목표 6등급도 가진 것으로 친다. 큰 쪽이 주력이다.
- **목표 고르기.** 처음부터 무작위가 아니라, 남은 1등급 값에서 "주력 계열과 같으면 2, 주력 계열을 돕는 효과(방깍·마깍·오라)가 있으면 2"를 뺀 점수가 가장 낮은 6등급을 고른다. 라운드가 바뀔 때 점수가 4 이상 낮은 목표가 있으면 바꾼다. 가산점 0·2·3·4를 8시드로 비교했는데 차이가 노이즈 수준이라 2로 정했다.
- **강화.** 주력 계열 강화와 등급 손질만 산다. 일반 6등급은 30종 모두 물리·마법 두 계열을 이어받아서, 한 계열에 몰아도 6등급은 전부 이득을 본다. 기존 봇은 가장 싼 것부터 사서 물딜·마딜을 반씩 나눈다.
- **남겨 둘 유닛.** 트리 밖이라도 주력 계열을 돕는 유닛을 4기까지 팔지 않는다(보스전용 전력 4기와 별도).
- **배치.** 근접은 가장자리, 원거리는 안쪽이라는 기존 규칙에 더해, 아군 오라(공격 속도·공격력) 유닛을 오라 반경 안 같은 계열 공격력 합이 가장 큰 칸으로 옮긴다. 같은 종류 칸끼리만 바꾸고, 25% 넘게 나아질 때만 옮긴다. 방깍 유닛의 사거리 배치와 적 대상 오라(`auraEnemyVuln`)의 사거리는 따로 계산하지 않았다.

### 초안 경제값에서 계단이 나오나

- **서툰 봇:** 6등급 0기, 패배 켬에서 대부분 11~20R에 탈락(120명 중 109명). 기대한 "중반 탈락"보다 이르다.
- **보통 봇:** 6등급이 거의 없다(0기 96%). 목표 없이 만들 수 있는 가장 높은 조합부터 하니 재료가 흩어진다. 그래도 20·30R 보스는 잡고 21~60R에 탈락하며, 팀 클리어는 절반(9/20)이다. "2기 전후" 칸에 이 봇은 맞지 않는다. 2기 칸은 목표 봇·전환 봇이 맡는다.
- **목표·전환 봇:** 2기 전후. 전환 봇은 패배 켬에서 3기 쪽으로 기운다.
- **시너지 봇:** 중앙값 3, 클리어 20/20, 완주 78%(패배 켬). 3~4기 비율이 55~64%라 70%에 못 미친다.

순서(서툰 < 보통 < 목표 < 전환 ≤ 시너지)는 나오지만, 맨 위 칸이 3~4기 70%에 닿지 않는다.

### 제안하는 판단 기준

`full-q2`, 20시드, 패배 켬/끔 기준:

1. **시너지 봇:** 완주자의 70% 이상이 3~4기, 중앙값 3~4, 0기 5% 이하, 패배 켬 완주 80% 이상, 팀 클리어 95% 이상.
2. **전환 봇**(목표는 재료에 맞추지만 시너지는 모름): 중앙값 2~3, 패배 켬 완주 60~80%.
3. **목표 봇**(무작위 목표 고정): 중앙값 2, 3~4기는 소수(30% 이하).
4. **보통 봇**(목표 없이 큰 조합부터): 6등급 거의 없음, 탈락은 대부분 21R 이후, 팀 클리어 절반 안팎.
5. **서툰 봇:** 20R 강철이 전후 탈락.
6. **운:** 같은 판 자리 간 표준편차 0.7기 이하.
7. **전투:** 시너지 봇 기준 역신 네 관문 처치 시간이 제한의 50~80%.

1번만 초안 경제값으로 못 맞춘다. 9장 이전의 합격선(양쪽 봇 모두 중앙값 3~4)은 목표 봇에게 시너지 봇과 같은 결과를 요구하는 셈이라, 위처럼 봇마다 칸을 나눠 보는 쪽을 제안한다.

지게(물)가 10/0에서 탈락하는 것만 결과와 쏠림 계열이 같다. 나머지는 모두 결과 계열의 반대쪽으로 쏠렸을 때다.

### 판단이 필요한 것 (32칸으로 잰 때)

1. 8×5 판의 시작 32칸이 고개를 크게 쉽게 만든다(보통 봇 완주 29 → 115자리, 전환 봇 완주 94%). 이대로 둘지, 시작을 세 줄 24칸으로 줄일지 등. → 아래 "시작 24칸"으로 결정됐다.
2. 전환 봇이 시너지 봇보다 6등급을 더 만든다. 계단 기준을 다시 볼지.
3. 셋째 역신 122,000 제안.
4. 강화 쏠림에서만 지는 조합 30~31개를 "조합은 언제나 이득" 대상에 넣을지. 넣으면 결과 유닛 수치보다 재료 계열 구성을 손봐야 하는 경우가 많다.
5. 칸 늘리기 3단계가 3·3·2칸을 여는 것(4단계 2칸씩으로 바꾸는 안도 있다).

### 시작 24칸 (디자이너 결정)

8×5 판의 시작을 세 줄 24칸으로 줄이고, 칸 늘리기를 네 단계 4칸씩(50·100·150·200냥, `stage3/upgrades.json`)으로 바꿨다. 다른 수치(셋째 역신 109,000 등)는 그대로다. 같은 명령(`full-q2`, 시드 1~20, 봇 다섯, 패배 켬/끔)으로 다시 쟀다. 앞 열은 위 표의 시작 32칸 값이다.

| 지표 | 시작 32칸 | 시작 24칸 |
| --- | ---: | ---: |
| 시너지 봇 3~4기, 패배 끔 / 켬 | 74.2% / 72.6% | **60.8% / 68.0%** |
| 시너지 봇 0/1/2/3/4/5+, 패배 켬 | 0/0/26/48/29/3 | 0/0/30/54/14/2 |
| 시너지 봇 완주, 패배 켬 (120자리) | 106 | 100 |
| 전환 봇 3~4기, 패배 끔 / 켬 | 80.0% / 77.0% | 67.5% / 75.0% |
| 전환 봇 완주, 패배 켬 | 113 (94%) | 104 (87%) |
| 목표 봇 3~4기, 패배 끔 / 켬 | 22.5% / 26.1% | 12.5% / 15.5% |
| 목표 봇 완주, 패배 켬 | 88 | 71 |
| 보통 봇 완주, 패배 켬 / 팀 클리어 | 115 / 20판 | 105 / 19판 |
| 서툰 봇 | 20라운드까지 전원 탈락 | 같음 (10라운드 전 55, 11~20라운드 65자리) |

역신 처치 시간(제한 시간 대비, 패배 켬, 첫째·둘째·셋째·넷째):

| 봇 | 시작 32칸 | 시작 24칸 |
| --- | --- | --- |
| 시너지 | 59.7 / 61.9 / 45.4 / 54.9% | 66.6 / 65.2 / **55.5** / 60.5% |
| 전환 | 60.0 / 59.5 / 41.3 / 51.5% | 61.6 / 60.7 / 48.4 / 59.4% |
| 목표 | 67.8 / 67.9 / 48.5 / 61.0% | 70.2 / 73.2 / 60.1 / 71.3% |
| 보통 | 55.2 / 60.9 / 78.0 / 79.5% | 61.0 / 66.6 / 80.5 / 84.5% |

패배 끔 시너지 봇은 66.6 / 65.2 / 60.5 / 66.9%다.

- 고개 난이도는 32칸과 옛 18칸 사이로 돌아왔다. 보통 봇 완주는 115 → 105자리로 아직 높고(옛 6×4 판은 29), 전환 봇 완주 87%도 2번 기준(60~80%)보다 높다.
- **셋째 역신은 체력을 바꾸지 않고도 범위에 들어왔다**(시너지 55.5%·60.5%, 전환 48.4%). 앞서 낸 122,000 제안은 필요 없어 보인다.
- **시너지 봇이 70% 아래로 내려갔다**(패배 끔 60.8%, 켬 68.0%). 2기에 멈춘 자리가 늘었다(끔 44자리). 전환 봇이 여전히 시너지 봇보다 높아 계단은 뒤집힌 채다.
- 지시대로 이번에는 다른 수치를 바꾸지 않았다. 다음 조정 후보는 공급을 늘리는 단일 값이다: 보따리 장날당 구매 한도 3 → 4회, 또는 시작 도깨비불 4 → 5개(앞서 5개 실험에서 셋째 역신이 빨라졌는데, 지금은 여유가 5%p 이상 있다).
