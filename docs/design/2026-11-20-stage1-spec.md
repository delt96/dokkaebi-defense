## 0. 범위

**넣는 것**
- 고개 하나, 칸 배치와 칸 사이 이동
- 소환, 고정 레시피 조합(1~4등급 22종), 판매
- 웨이브 20라운드, 고개 보스 2번(10·20라운드)
- 잡귀 한도 패배, 고개 보스 실패 패배, 20라운드 클리어
- 유닛 스킬(효과 종류 11가지의 조합, 4.6)과 상태 이상
- 강화 (8장)
- 조합 도우미와 도감, 도우미 연 횟수
- 칸별 사거리 표시
- 결과 화면(라운드별 남은 잡귀 그래프)
- 화면 없이 도는 시뮬레이터와 기준 봇 2종(서툰 봇, 보통 봇). 여유가 있으면 잘하는 봇을 더한다

**빼는 것** (설계 문서 10.1의 다음 단계)
- 멀티, 공유 보스, 넋, 퀘스트, 5·6등급, 뽑기 장터, 지게 도깨비
- 계정, 랭킹
- 조합 도우미의 목표 고정 기능
- 사운드: 효과음을 붙일 자리만 만들어 둔다
- 튜토리얼, 모바일 정식 대응

**처음부터 다음 단계를 전제로 짜는 것**
- 게임 로직은 고개 수 N을 받는다. 1단계는 N=1로 돌린다.
- 같은 시드와 같은 입력이면 같은 결과가 나온다(4.5). 시뮬레이터와 서버 판정(2단계)이 이것에 기댄다.
- 고개 경로에 역신 출입구 자리를 둔다(1장). 2단계 공유 보스가 쓴다.

## 1. 고개 구조

- 길이 단위는 칸이다. 1칸 = 32px, 화면에는 2배(64px)로 보인다.
- 배치 칸: 가로 6 × 세로 4 = 24칸. 칸 번호는 왼쪽 위부터 오른쪽으로, 줄 단위로 0~23이다.
- 24칸이 처음부터 모두 열려 있다. 예전에는 아래 줄 6칸을 칸 늘리기 강화로 열었지만 2026-11-23에 강화를 없앴다(8장).
- 경로: 칸 격자에 바로 붙은 직사각형 고리다. 경로 중심선은 격자 가장자리에서 0.5칸 밖에 있어서 가로 7칸 × 세로 5칸 크기이고, 한 바퀴가 24칸이다.
- 잡귀는 왼쪽 위 모서리에서 나와 시계 방향으로 끝없이 돈다. 마을로 빠져나가지 않는다(설계 문서 4.2 장승).
- 역신 출입구: 잡귀가 나오는 왼쪽 위 모서리. 2단계 역신은 여기로 들어와 한 바퀴 돈 뒤 같은 곳으로 나가 다음 고개로 간다.
- 장승: 경로 바깥의 배경 소품이다. 잡귀 수가 한도에 가까울수록 금이 간다.

```
  ○→→→→→→→○        ○ 경로 (시계 방향), 왼쪽 위가 등장 지점이자 역신 출입구
  ↑■■■■■■↓        ■ 가장자리 칸 (16)
  ↑■□□□□■↓        □ 안쪽 칸 (8, 처음부터 열림): 사거리 2.5 이상만 닿음
  ↑■□□□□■↓
  ↑■■■■■■↓
  ○←←←←←←←○  [장승]
```

**칸 위치와 사거리**

칸 중심에서 경로까지의 거리가 칸 위치마다 다르다. 가장자리 칸은 1.0, 안쪽 칸은 2.0이다. 칸 하나가 사거리 안에 두는 경로 길이는 아래와 같다. 모서리 칸은 두 변에 걸쳐 더 길다.

| 사거리 | 가장자리 칸 | 안쪽 칸 |
| --- | --- | --- |
| 1.5 | 2.2칸 | 닿지 않음 |
| 2.0 | 3.5칸 | 닿지 않음 |
| 2.5 | 4.6칸 | 3.0칸 |
| 3.0 | 5.7칸 | 4.5칸 |

- 근거리(사거리 2.0 이하)는 가장자리에, 원거리는 안쪽에 두는 배치 고민이 생긴다. 의도한 구조다.
- 안쪽 칸은 둘째·셋째 줄 가운데 4칸씩, 8칸이다. 경로는 처음부터 24칸 격자 전체를 둘러싸고 있어서 아래 줄이 닫혀 있어도 이 8칸은 안쪽 칸이다. 처음 열린 18칸은 가장자리 10칸과 안쪽 8칸이다.
- 유닛을 고르거나 끌면, 그 칸에서 사거리가 닿는 경로 구간을 밝게 표시한다.

## 2. 라운드 흐름

- 일반 라운드는 40초로 정해져 있다. 잡귀를 다 잡지 못해도 다음 라운드가 시작된다(설계 문서 5.2).
- 라운드 시작: 도깨비불 2개 지급 → 잡귀 30마리가 0.8초 간격으로 등장(약 24초) → 남은 16초 → 다음 라운드.
- 보스 라운드(10·20): 75초. 잡귀 대신 보스 한 마리가 등장 지점에서 나온다. 앞 라운드에서 남은 잡귀는 계속 돈다. 일찍 잡으면 남은 시간은 준비 시간이다. 도깨비불 2개와 라운드 끝 엽전은 일반 라운드와 같이 받는다.
- 판 시작 전 준비 시간 20초. 이때 도깨비불 4개를 받는다.
- 한 판: 준비 20초 + 일반 18라운드 × 40초 + 보스 2라운드 × 75초 = 약 15분.
- 소환, 조합, 판매, 강화, 이동은 언제든 할 수 있다. 일시정지는 1인 판에서만 허용한다.

## 3. 적

### 3.1 잡귀 3종

| 이름 | 체력 | 속도(칸/초) | 저항 | 모습 |
| --- | --- | --- | --- | --- |
| 잡귀 | HP(r) | 1.6 | 없음 | 산발 머리, 연보라 테두리 빛 (샘플 v2) |
| 그슨대 | HP(r) | 2.2 | 물딜 −50% | 키 큰 그림자. 형체가 흐림 |
| 두억시니 | HP(r) × 1.5 | 1.1 | 마딜 −50% | 다부진 덩어리. 단단함 |

- 체력 시작 공식: HP(r) = round(40 + 12 × r^1.5). r은 라운드 번호다. 1라운드 52, 10라운드 420, 19라운드 1,030.
- 첫 초안(4 × r^1.7)은 보통 봇 화력이 필요량의 1.5~33배라 너무 쉬웠다(Fable 계산). 새 공식은 보통 봇 기준 배율 1.2~1.5를 노린다.
- 원본처럼 지수로 부풀리지 않는다(설계 문서 8장).
- 잡귀는 공격하지 않는다. 위협은 쌓이는 수뿐이다.
- 끝없이 도는 고리에서는 속도가 웨이브 난이도에 큰 영향이 없다. 그슨대와 두억시니의 차이는 저항이 만든다.

### 3.2 라운드 구성

| 라운드 | 구성 |
| --- | --- |
| 1, 2, 4, 5, 7, 11, 14 | 잡귀 30 |
| 3, 8, 13, 17 | 그슨대 30 |
| 6, 9, 15, 18 | 두억시니 30 |
| 12, 16, 19 | 섞임 (잡귀·그슨대·두억시니 10씩, 번갈아 등장) |
| 10 | 고개 보스: 지네각시 |
| 20 | 고개 보스: 강철이 |

### 3.3 고개 보스 2종

| 이름 | 라운드 | 체력 (시작값) | 속도 | 저항 |
| --- | --- | --- | --- | --- |
| 지네각시 | 10 | 3,000 | 0.9 | 없음 |
| 강철이 | 20 | 8,000 | 0.9 | 마딜 −30% |

- 보스는 한 마리라 유닛마다 사거리가 닿는 구간에 있을 때만 때린다. 그래서 체력은 "라운드 체력 합의 몇 %"가 아니라, 보통 봇이 75초 중 50~65초에 잡도록 시뮬레이터로 맞춘다.
- 스턴과 둔화는 보스에게 시간 절반만 걸린다. 밀어내기도 절반 거리다.
- 보스는 "남은 몹 수"에 세지 않는다(설계 문서 5.3).
- 설화 출처 확인은 콘텐츠 단계에서 한다. 1단계는 이름이 임시여도 된다.

## 4. 전투 규칙

### 4.1 유닛 능력치

- 능력치: 계열(물딜/마딜), 공격력, 공격 간격(초), 사거리(칸), 스킬.
- 등급별 기준 초당 피해(DPS): 1등급 10, 등급이 하나 오를 때마다 ×2.6. 2등급 26, 3등급 68, 4등급 176. 5·6등급은 457, 1,188이 된다.
- 유닛 공격력 = 등급 기준 DPS × 공격 간격 × 개성 계수. 개성 계수는 사거리가 길거나 범위 스킬이 있으면 낮게, 근거리 단일이면 높게 준다(10장 표).
- 재료 대비 화력이 항상 오르게 한다. 1등급 값 하나당 DPS가 1등급 10 → 2등급 13 → 3등급 17 → 4등급 22로 오른다(재료 값은 6장). 그래서 조합은 언제나 이득이다.
- 계수 차이가 사거리 값을 제대로 매기는지(근거리는 웨이브에서, 원거리는 보스에서 유리)는 시뮬레이터의 보스 처치 시간과 웨이브 배율로 확인한다.

### 4.2 공격

- 사거리 안의 적 중 보스를 먼저 치고, 없으면 가장 먼저 나온 잡귀를 친다.
- 공격은 공격 간격마다 바로 판정한다. 투사체가 날아가는 모습은 화면 연출일 뿐이다(설계 문서 9.3).
- 사거리는 칸 중심에서 적까지의 직선 거리로 잰다. 칸마다 사거리가 닿는 경로 구간은 판 시작 때와 칸이 열릴 때 미리 계산한다.
- 공격 타이머: 공격하면 간격만큼 기다린다. 대상이 없으면 준비된 채로 기다리다가 대상이 들어오는 틱에 바로 친다. 소환·조합 직후에는 준비된 상태로 시작한다.

### 4.3 피해 계산

```
피해 = 공격력 × 스킬 배율
     × (1 + 계열 강화 보너스 + 등급 손질 보너스 + 오라 공격력 보너스)
     × (1 − 대상 저항)
     × (1 + 대상이 받는 피해 증가)
```

- 강화와 오라는 더한 뒤 곱한다. 서로 곱하면 후반에 숫자가 튄다.
- 스킬로 들어가는 피해(범위, 지속, 불길, 폭발)도 모두 위 식을 따른다. 공격력 대신 "공격력 × 스킬 배율"을 넣는다.
- 받는 피해 증가는 계열을 가린다. 다듬이방망이와 모루의 깎기는 물딜에만 붙고, 장독 오라는 둘 다에 붙는다.
- 피해는 계산 후 반올림해 정수로 만든다. 최소 1이다. 체력도 정수다.

**공격 속도**

```
실제 공격 간격 = 기본 간격 ÷ (1 + 공속 보너스 합)
```

- 청사초롱과 달집처럼 다른 오라의 공속 보너스는 더한다. 같은 오라 여러 개는 하나만 친다.

### 4.4 상태 이상

| 효과 | 규칙 |
| --- | --- |
| 스턴 | 그 시간 동안 멈춤. 다시 걸리면 남은 시간이 긴 쪽을 따른다. 보스는 시간 절반 |
| 둔화 | 속도 −N%. 여러 개면 가장 센 것 하나만. 보스는 시간 절반 |
| 밀어내기 | 경로를 거꾸로 N칸 되돌림. 보스는 절반. 등장 지점 앞으로는 밀리지 않음 |
| 받는 피해 증가 | 같은 출처는 겹치지 않고 시간만 새로 고친다(모루만 중첩). 다른 출처끼리는 더한다. 합 최대 +50% |
| 지속 피해 | 걸 때 총 피해량을 정하고 0.5초마다 나눠 넣는다. 같은 출처가 다시 걸리면 남은 피해를 버리고 새로 건다 |
| 바닥 불길 | 경로 위 구간에 남아, 0.5초마다 그 위에 있는 적에게 피해. 같은 출처의 불길이 겹친 곳에서는 하나만 친다 |
| 오라 | 범위 안 아군이나 적에게 상시 적용. 같은 오라는 겹치지 않고 다른 오라끼리는 더한다 |

- "같은 출처"는 유닛 종류를 뜻한다. 호롱 두 개의 불씨는 겹치지 않는다. 같은 유닛을 여러 개 놓는 것보다 다른 유닛을 섞는 편이 낫게 만든다.
- 유닛이 팔리거나 조합에 쓰여도, 이미 건 지속 피해와 불길은 끝까지 남는다. 오라는 그 순간 사라진다.
- 속도가 바뀌면 그 순간의 위치와 새 속도를 이벤트로 남긴다(설계 문서 9.3). 1단계는 1인이지만 같은 구조로 짠다.

### 4.5 틱, 처리 순서, 난수

- 게임 로직은 50ms 고정 틱(초당 20틱)으로 진행한다.
- 한 틱 안의 처리 순서:
    1. 플레이어 명령 처리 (소환, 조합, 판매, 강화, 이동). 받은 순서대로
    2. 잡귀 등장
    3. 적 이동
    4. 상태 이상 시간 감소, 지속 피해와 불길 피해
    5. 유닛 공격. 칸 번호 순서대로
    6. 처치 처리와 보상
    7. 한도와 보스 제한 시간 판정
- 난수: 판 시드에서 흐름을 갈라 따로 쓴다. 소환용 하나, 전투 발동용 하나. 2단계에서는 플레이어마다 소환 흐름을 따로 둔다. 남의 소환이 내 전투 결과를 바꾸지 않게 하기 위해서다.
- 범위와 거리는 모두 직선 거리다. "주변 1.5칸"은 기준점에서 반지름 1.5칸 원 안이다.
    - 아군 오라(자기 칸 기준): 반지름 1.5면 둘러싼 8칸이다.
    - 적 대상 범위: 맞은 적 위치 기준이다.
    - 적에게 거는 오라: 그 유닛의 사거리 안이다.

### 4.6 스킬 효과 11가지

유닛마다 고유 스킬을 가진다(설계 문서 6.2-1). 구현은 아래 효과 종류를 조합하고 수치를 바꾸는 방식으로 한다.

| 효과 | 설명 |
| --- | --- |
| 추가 공격 | 한 번 더 친다. 추가 공격으로는 스킬이 다시 발동하지 않는다 |
| 강타 | 피해 배율. 확률 또는 N번째 공격마다 |
| 처형 | 체력이 N% 이하인 대상에게 피해 배율 |
| 범위 피해 | 맞은 적 주변 반지름 안의 적에게 피해 |
| 관통 | 대상과 그 뒤를 따라오는 경로 N칸 안의 적에게 피해 |
| 주기 범위 | N초마다 사거리 안 모든 적에게 피해 |
| 스턴, 둔화, 밀어내기 | 4.4 |
| 받는 피해 증가 | 4.4 |
| 지속 피해 | 4.4 |
| 바닥 불길 | 4.4 |
| 오라 | 아군 공격력·공속, 적이 받는 피해 |

- 처치로 터지는 폭발은 다시 폭발을 부르지 않는다.
- N번째 공격 카운터와 중첩은 이동해도 남는다. 조합이나 판매로 유닛이 없어지면 사라진다.

## 5. 소환

- 뚝딱 버튼: 도깨비불 1개로 유닛 하나를 뽑는다.
- 확률: 1등급 70%, 2등급 25%, 3등급 5%. 같은 등급 안에서는 1단계에 있는 유닛 중 균등하게 나온다.
- 소환 보정: 1등급이 나온 소환이 7번째가 될 때마다 그 소환 자체가 지금까지 가장 적게 뽑은 1등급으로 바뀐다. 유닛을 더 주지 않으므로 소환 한 번은 언제나 유닛 하나다. 같은 수면 1등급 목록 순서(10장)를 따른다. 난수는 소환마다 한 번만 뽑고, 1등급이 나왔을 때 그 결과를 바꾼다. 소환은 빈칸이 있어야 하므로 보관해 둘 유닛이 생기지 않는다.
- 놓는 자리: 사거리 2.0 이하는 열린 빈 가장자리 칸, 2.5 이상은 열린 빈 안쪽 칸을 먼저 쓴다. 맞는 칸이 없으면 다른 쪽 빈 칸에 놓는다. 같은 조건이면 칸 번호가 작은 쪽이다.
- 빈 칸이 하나도 없으면 뚝딱 버튼이 잠긴다.
- 연출: 불꽃 색으로 등급을 먼저 보여 주고, 다음에 물건 실루엣이 드러난다. 3등급이 나오면 화면을 흔든다.

## 6. 조합

### 6.1 레시피 형태 (제안, 설계 문서 6.2 표를 고침)

비용을 "1등급 값"으로 잰다. 1등급 하나가 1이다.

| 결과 | 재료 | 1등급 값 |
| --- | --- | --- |
| 2등급 | 1등급 2 | 2 |
| 3등급 | 2등급 1 + 1등급 2 | 4 |
| 4등급 | 3등급 1 + 2등급 2 | 8 |
| 5등급 (3단계) | 4등급 2 + 메밀묵 | 16 |
| 6등급 (3단계) | 5등급 2 + 특정 3·4등급 1 + 메밀묵 + 엽전 | 36~40 |

- 설계 문서 6.2 형태는 6등급 하나에 90~135가 들어 목표(판당 3~4개)에 맞지 않았다. 단계마다 약 2배로 줄였다. 근거는 11장 표.
- 3·4등급 레시피에 아래 등급이 다시 들어가서, 1등급이 여러 레시피에 쓰이고 남는 재료가 줄어든다.

### 6.2 조합 조작

- 조합 도우미의 "지금 만들 수 있는 것" 목록에서 결과를 누르면 바로 조합한다.
- 결과 자리: 재료 중 등급이 가장 높은 것의 칸이다. 같은 등급이면 칸 번호가 작은 쪽이다.
- 같은 유닛이 여러 개면 결과 자리로 정한 개체를 먼저 쓰고, 나머지는 칸 번호가 큰 쪽부터 쓴다.
- 유닛을 누르면 정보 카드에 "이 유닛이 들어가는 레시피"가 나온다.
- 도우미 패널을 펼친 횟수를 센다. 결과 화면에 "도우미 N회"를 표시한다(설계 문서 6.2).
- 도감: 22종 전체와 레시피를 판 안에서 볼 수 있다.

## 7. 경제

| 자원 | 얻는 곳 | 쓰는 곳 (1단계) |
| --- | --- | --- |
| 도깨비불 | 준비 4개, 라운드마다 2개 | 뚝딱, 엽전으로 바꾸기 |
| 엽전 | 잡귀 처치 1냥, 라운드 끝 10냥, 고개 보스 60냥 | 강화 |
| 메밀묵 | 고개 보스 2개 | 1단계에서는 쓰지 않고 모으기만 함 (8장 결정에 따라 바뀜) |

- 도깨비불 바꾸기: 1개 → 엽전 25냥. 손해인지 이득인지는 강화 비용과 함께 시뮬레이터로 맞춘다.
- 1단계에서 쓸 수 있는 양: 도깨비불 44개. 엽전은 잡귀를 다 잡았을 때 약 790냥이다. 20라운드 보스 보상과 마지막 라운드 끝 보상은 판이 끝나서 못 쓴다. 메밀묵은 2개다.
- 처치 보상은 확률 없이 고정이다. 시뮬레이터가 결과를 읽기 쉽게 하기 위해서다. 설계 문서 8.1의 "확률형"을 이쪽으로 고친다.
- 판매: 1등급 5냥, 2등급 10냥, 3등급 20냥, 4등급 40냥. 들인 값의 약 30%라서, 막힌 레시피를 풀 수단은 되지만 돈벌이는 되지 않는다. 메밀묵 환급은 5·6등급이 생기는 3단계부터 둔다.

## 8. 강화: 1단계는 네 갈래, 3단계에 추가 (결정, 사용자)

사용자는 "다양하게"를 원했다. 처음에 여섯 갈래로 짰지만, Fable 계산으로는 헌물건 손질만 올리는 게 정답이었다. 막물건 손질, 장승 강화, 뚝딱 강화는 쓸 일이 거의 없었다. 그래서 1단계에 네 갈래를 두고 단가를 맞춘 뒤, 3단계에서 갈래를 늘린다.

| 강화 | 효과 | 단계 | 비용 |
| --- | --- | --- | --- |
| 물딜 강화 | 물딜 유닛 공격력 +10% | 최대 10 | 엽전 25 × 단계 |
| 마딜 강화 | 마딜 유닛 공격력 +10% | 최대 10 | 엽전 25 × 단계 |
| 등급 손질 | 1~4등급 전체 공격력 +6% | 최대 10 | 엽전 25 × 단계 |

- 칸 늘리기(아래 줄 2칸씩, 50냥 × 단계, 최대 3)는 2026-11-23에 모든 단계에서 없앴다. 24칸이 처음부터 열린다.
- 단가 맞춤: 물딜·마딜 반반이면 계열 강화 한 단계는 전체 +5%다. 등급 손질은 전체 +6%지만 한쪽 계열로 몰아 짠 판에서는 계열 강화(+10%)가 낫다. 그래서 "몰아 짜면 계열, 섞으면 손질"이라는 고민이 생긴다.
- 등급 손질은 등급 묶음을 없앴다. 묶음으로 나누면 조합 때 효과가 다른 묶음으로 넘어가 막물건 손질이 함정이 되었기 때문이다.
- 790냥으로 강화 세 갈래를 합쳐 약 12단계(1+2+…, 갈래마다 4단계 남짓) 올릴 수 있다. 다 올릴 수는 없다.
- 3단계에 더할 후보: 뚝딱 강화(메밀묵으로 소환 확률), 장승 강화(잡귀 한도). 메밀묵이 5·6등급 재료가 되는 3단계에서 값을 다시 매긴다.

## 9. 패배와 클리어

- 잡귀 한도: 60마리. 잡귀 수가 60을 넘은(61 이상) 상태가 5초 이어지면 탈락한다. 60 이하로 내려가면 5초 타이머는 처음부터 다시 센다. 넘는 순간 장승이 흔들리고 화면 가장자리가 붉어진다.
- 고개 보스: 75초 안에 못 잡으면 탈락한다. 모든 난이도에 적용한다(설계 문서 7.1-1).
- 클리어: 20라운드 보스를 잡는 순간 클리어가 확정된다. 그 순간 한도를 넘은 상태여도 클리어다.
- 결과 화면:
    - 클리어 또는 탈락, 버틴 라운드
    - 라운드별 "우리 고개 잡귀" 그래프. 마지막 값과 가장 많았던 값
    - 만든 최고 등급 유닛
    - 도우미 N회
    - 다시 하기 버튼

## 11. 수입 대 비용 표 (설계 문서 6.1 목표 "어려움 판당 6등급 3~4개" 확인)

가정:
- 도깨비불 하나 = 1등급 값 1.4 (0.70×1 + 0.25×2 + 0.05×4). 소환 보정은 1등급 하나를 다른 1등급으로 바꿀 뿐이라 값을 더하지 않는다
- 도깨비불의 80%를 소환에 쓰고 20%를 엽전으로 바꾼다
- 고정 레시피라 맞지 않아 버리거나 파는 재료가 15%

| 구간 | 도깨비불 | 소환에서 오는 값 | 버림 뺀 값 | 필요 값 |
| --- | --- | --- | --- | --- |
| 1단계 20R | 44 | 49 | 42 | 4등급 3~4개(24~32) + 아래 등급 |
| 쉬움 40R | 84 | 94 | 80 | 5등급 2~3개 + 6등급 1개 노림 |
| 어려움 60R | 124 | 139 | 118 | 6등급 3.5개(133) + 5등급 2개(32) + 기타 ≈ 190 |

- 어려움에서 도깨비불만으로는 약 70이 모자란다. 이 몫은 3단계에서 붙는 수입으로 채운다. 설계 문서 8.2 원칙대로 퀘스트 몫은 전체 수입의 25% 안에 둔다.
    - 뽑기 장터(엽전 → 랜덤 유닛) 약 40
    - 퀘스트와 도전과제 약 20
    - 고개 보스·공유 보스 보상 약 10
- 메밀묵: 어려움에서 6등급 3.5개와 5등급 2개를 만들려면 약 12개가 든다(레시피당 1개 가정). 고개 보스 6번 × 2개와 맞아떨어져 다른 데 쓸 몫이 없다. 3단계에서 뚝딱 강화를 넣는다면 메밀묵 수입도 함께 늘린다.
- 1단계 20라운드는 도깨비불만으로 4등급 3~4개가 나온다. 판 끝에 4등급을 몇 개 만드느냐가 1단계에서 실력이 드러나는 지점이 된다.

## 12. 시뮬레이터

- 게임 로직 모듈을 화면 없이 그대로 돌린다. 시드를 고정하면 같은 결과가 나온다.
- 기준 봇:
    - 서툰 봇: 도깨비불을 전부 소환에 쓰고, 만들 수 있는 조합을 무작위로 한다. 자동 배치 자리 그대로 두고 강화하지 않는다.
    - 보통 봇: 높은 등급 조합을 먼저 하고, 엽전이 모이면 가장 싼 강화부터 올린다. 근거리는 가장자리, 원거리는 안쪽으로 옮긴다. 보스 라운드에는 사람처럼 보스를 따라 유닛을 옮긴다(2초마다, 보스에 가까운 가장자리 칸으로 근거리 유닛 몇 개).
    - 잘하는 봇 (여유가 있으면): 목표 4등급 2~3개를 정해 레시피를 거꾸로 따라간다. 물딜·마딜 비율을 맞추고, 오라 유닛 주변에 공격 유닛을 모은다.
- 지표 정의:
    - 배율 = 그 라운드에 실제로 넣은 피해 ÷ 그 라운드 잡귀 체력 합. 1보다 크면 그 라운드 잡귀를 다 잡을 힘이 있다.
    - 라운드 중 최대 잡귀 수
    - 보스 처치 시간
- 1단계 목표:
    - 서툰 봇은 12~20라운드 사이에 탈락한다
    - 보통 봇은 클리어한다. 일반 라운드 배율이 대체로 1.2~1.5, 라운드 중 최대 잡귀가 15~40, 보스 처치 시간이 50~65초다
    - "라운드 끝 잡귀 10~30" 같은 지표는 쓰지 않는다. 배율이 1을 넘으면 0으로 가고 못 미치면 계속 쌓여서, 그 구간에 머물지 않기 때문이다
- 출력: 라운드별 배율, 라운드 끝·최대 잡귀, 총 DPS, 수입, 보유 등급 분포, 보스 처치 시간을 CSV로 낸다. 시드 100개를 돌려 분포를 본다.
- 11장 수입 대 비용 표를 계산하는 스크립트도 함께 둔다. 3단계에서 5·6등급을 넣을 때 다시 쓴다.
- 이동 제약이 없어서(13장) 보스 처치 시간은 따라 옮기기를 하느냐에 크게 달린다. 보통 봇에 따라 옮기기를 넣고, 서툰 봇(옮기지 않음)과의 처치 시간 차이도 함께 본다. 서툰 봇이 보스를 못 잡는 것은 의도한 결과다.

## 13. 화면 구성과 조작

기준 해상도는 640×360이고, 화면에는 정수 배로 확대한다(1280×720이면 2배). 가로 화면이다.

```
┌──────────────────────────────────────────────────────────────┐
│ 12 / 20 라운드   남은 23초        우리 고개 잡귀 18 / 60  [장승] │
├──────────────┬────────────────────────────────┬──────────────┤
│ 조합 도우미    │                                │ 도깨비불 3     │
│ 만들 수 있음   │      경로 고리 + 칸 격자          │ 엽전 240      │
│  가마솥 [조합] │                                │ 메밀묵 1      │
│  멍석   [조합] │                                │              │
│              │                                │ [ 뚝딱! ]     │
│ [도감]        │                                │ [불 바꾸기]   │
│              │                                │ [강화]        │
├──────────────┴────────────────────────────────┴──────────────┤
│ 선택: 솥뚜껑 · 1등급 · 물딜 · 20% 스턴 · 쓰이는 곳: 가마솥, 장독 [판매] │
└──────────────────────────────────────────────────────────────┘
```

- 이동: 유닛을 끌어 빈 칸으로 옮기고, 다른 유닛 위에 놓으면 자리를 맞바꾼다. 끄는 동안 놓을 칸의 사거리 구간을 밝게 보여 준다.
- 이동 제약 없음 **(결정, 사용자)**: 옮긴 유닛은 바로 공격할 수 있고 횟수 제한도 없다. 보스를 따라 유닛을 옮기며 잡는 손놀림이 실력이 된다. 대신 보스 체력은 "따라 옮기는 플레이"를 기준으로 맞춘다(12장).
- 유닛을 누르면 아래에 정보 카드가 뜬다.
- 강화 버튼은 강화 창을 연다. 각 갈래에 현재 단계, 효과, 다음 비용을 보여 준다.
- 단축키(PC): 스페이스 뚝딱, 1~4 강화, Q 도우미 펼치기.
- 버튼과 칸은 화면에서 최소 44px 이상으로 잡는다. 나중에 터치로 누를 수 있게 하기 위해서다.

## 14. 데이터 파일

필드 이름은 빌더 재량(설계 문서 10.3)이다. 아래는 형태만 보여 준다.

| 파일 | 내용 |
| --- | --- |
| `units.json` | 22종 능력치, 스킬 |
| `recipes.json` | 결과 ← 재료 목록, 추가 비용 |
| `enemies.json` | 잡귀 3종, 보스 2종 |
| `waves.json` | 라운드별 구성 |
| `balance.json` | 체력 공식 계수, 등급 기준 DPS, 수입, 판매가, 한도, 틱 길이 |
| `upgrades.json` | 강화 갈래 |

```json
{
  "id": "sotlid",
  "name": "솥뚜껑",
  "grade": 1,
  "damageType": "physical",
  "range": 1.5,
  "interval": 1.2,
  "factor": 1.1,
  "skills": [{ "effect": "stun", "trigger": { "chance": 0.20 }, "duration": 0.5 }]
}
```

- 스킬은 4.6 효과 종류 중 하나와 발동 조건(확률, N번째 공격, 상시, 주기), 수치로 적는다.
- 검증 스크립트:
    - 모든 2등급 이상이 만들어질 수 있는지
    - 레시피에 없는 유닛을 참조하지 않는지
    - 1~3등급이 위 레시피에 쓰이는지
    - 레시피의 1등급 값이 6.1 표와 맞는지
    - 1등급이 물딜·마딜 레시피 양쪽에 쓰이는지 (1단계는 경고, 116종에서는 통과 조건)

## 15. 1단계가 끝났다고 보는 기준

1. 브라우저에서 혼자 20라운드를 처음부터 끝까지 할 수 있다. 클리어와 탈락 둘 다 나온다.
2. 22종 유닛, 잡귀 3종, 보스 2종, 강화, 상태 이상이 명세대로 동작한다.
3. 같은 시드와 같은 입력으로 두 번 돌리면 결과가 같다.
4. 시뮬레이터가 서툰 봇과 보통 봇으로 돌고, 12장 목표에 가깝다.
5. 게임 로직에 단위 테스트가 있다. 피해 계산, 공격 속도, 상태 이상 겹침 규칙, 조합 자리 선택, 소환 보정, 패배 판정, 틱 처리 순서.
6. 데이터 검증 스크립트가 통과한다.
7. 직접 해 봤을 때 "한 판 더"가 나오는지 사용자가 판단한다.

## 16. 1단계에서 정하지 않는 것

- 난이도 단계 수와 이름: 1단계는 한 난이도만 있다.
- 116종 전체 목록, 5·6등급, 설화 도깨비: 3단계 명세
- 멀티 동기화 세부, Colyseus 상태 구조, 역신의 고개 간 이동 규칙: 2단계 명세
- 사운드 방침, 튜토리얼: 2단계 플레이판 전에 정한다
