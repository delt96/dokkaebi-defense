# 6인전 화면 배치 초안

첫 6인 플레이판에는 **내 고개를 가운데 두고, 왼쪽에 여섯 고개의 잡귀 수를 세로로 붙이는 A안**을 권한다. 보스를 따라 유닛을 옮기는 동안 필요한 건 내 고리 전체다. 옆 사람이 얼마나 밀렸는지는 고개 번호와 잡귀 수 한 줄로 알 수 있다.

아래 치수와 배치는 제안값이다. 2단계에서 먼저 쓰는 협동 기능은 스코어보드, 역신, 개인 탈락과 넋 지원이다. 지게 도깨비 양도는 3단계에 붙일 자리를 함께 그렸다.

## 언제 무엇을 보여 줄까

| 구분 | 화면에 둘 내용과 조작 |
| --- | --- |
| 항상 · 내 고개 | 6×4 배치 칸(처음에는 아래 여섯 칸이 잠김), 바깥 고리, 왼쪽 위 출입구, 장승. 라운드와 남은 시간, 내 잡귀 수와 한도를 붙여 본다. 유닛을 끌면 놓을 칸에서 공격할 수 있는 길이 밝아진다. 빈 칸에 놓으면 이동하고, 다른 유닛 위에 놓으면 둘의 자리를 바꾼다. |
| 항상 · 여섯 고개 | 고개 번호를 고정하고 내 자리에 ‘나’를 붙인다. 각 고개에 직전 라운드 종료 시점의 잡귀 수를 표시한다. 첫 집계 전에는 ‘–’로 둔다. 생존, 재접속 대기, 탈락(넋)을 구분하고 탈락 자리를 당겨 채우지 않는다. 고개 보스·역신 등 특수 적은 잡귀 수에서 뺀다. |
| 항상 · 소환과 관문 | 뚝딱 버튼에 도깨비불로 지금 뽑을 수 있는 횟수를 적는다. 옆의 ‘보정까지 1등급 2회’는 1등급이 두 번 더 나오면 그 두 번째가 가장 덜 뽑은 1등급으로 바뀐다는 뜻이다(유닛을 더 주지는 않는다). 관문이 있는 판은 목표 단계와 마감 라운드를 표시한다. 역신이 돌고 있을 때는 공용 체력과 현재·다음 고개를 함께 본다. |
| 필요할 때 | 유닛을 누르면 선택 카드에 이름과 지금 만들 수 있는 결과가 뜬다. PC에서는 결과 옆의 Z/X/C 중 하나를 누르는 즉시 조합하고, 터치에서는 같은 결과 버튼을 한 번 누른다. 스킬 설명·판매는 카드 상세에서, 부족한 재료와 전체 레시피는 도우미·도감에서 본다. 강화와 불 바꾸기는 비용·잔액을 각 창에 함께 표시한다. |

**상황이 생겼을 때**

| 시점 | 표시와 입력 |
| --- | --- |
| 역신이 내 고개를 지날 때 | 직전 고개에서 ‘다음은 내 고개’를 표시한다. 역신이 왼쪽 위로 들어오면 고리 위 실제 위치에 탈 표식을 붙인다. 잡귀와 함께 시계 방향으로 한 바퀴 도는 동안 계속 끌어 옮길 수 있다. 나가면 다음 고개로 표식이 넘어간다. 단계마다 달라지는 출발점과 탈락 고개의 빠른 통과를 실제 진행에 맞춰 표시한다. |
| 누군가 탈락할 때 | 해당 자리에 ‘탈락 · 넋’을 남기고 원인(잡귀 한도 초과 또는 고개 보스 시간 초과)을 잠깐 띄운다. 내가 탈락하면 소환·조합 자리에 지원 토큰 잔량과 보낼 고개 선택이 뜬다. 생존자는 그대로 싸운다. 스토리 관문 실패 때는 전원 결과 화면으로 넘어간다. |
| 넋의 지원이 도착할 때 | 받은 사람에게 ‘3번 넋이 지원 토큰을 보냈습니다’와 받은 양을 표시한다. 수락 조작은 없다. 보내는 쪽에서는 라운드마다 받은 토큰으로 생존자를 고르며, 받을 수 있는 상한에 닿은 고개는 선택을 막고 이유를 적는다. |
| 지게 양도 요청이 올 때 | 조작 패널에 보낸 사람, 유닛 이름·등급, 수락·거절을 띄운다. 받는 사람이 수락해 양도가 끝나면 양쪽에 메밀묵 보상을 표시한다. 보내기는 지게 도깨비의 능력으로만 열고, 4등급 이하 한 기를 고른다. 다시 쓸 때까지 남은 시간을 지게 카드에 둔다. |
| 라운드가 끝날 때 | 여섯 자리의 수치를 같은 시점에 갱신하고 ‘12라운드 끝’처럼 집계 시점을 붙인다. 다음 라운드에도 펼쳐 볼 수 있게 두며 확인 버튼으로 전투를 끊지 않는다. 판이 끝나면 각자 마지막 라운드 끝 수치와 판 중 최대치를 함께 본다. |

## 세 가지 배치

도면의 숫자는 640×360 기준 px이며 테두리를 포함한다. 내 고개는 한 칸 32px, 격자 192×128, 고리 중심선 224×160이다. 휴대폰 예시는 가로세로 비가 약 2.0~2.2인 화면 중 800×370 CSS px를 기준으로 한다. 지금 방식대로 1·1.5·2·3…배 중 하나를 골라 가운데 놓으면 여기서는 1배이고 좌우로 80px씩 남는다. 아래 휴대폰 안은 그 여백까지 써서 칸과 주요 버튼을 44px 이상으로 잡는 별도 배치다. 44px 칸 여섯 열과 네 줄에 바깥 길 한 칸씩을 두르면 352×264가 필요하다.

### A. 왼쪽 여섯 줄, 가운데 내 고개

```text
+----------------------------------------------------------------+
| 라운드 · 남은 시간 · 내 잡귀/한도 · 관문                 640x24 |
+-------------+-----------------------------------+--------------+
| 직전 R 끝   | 내 고개                           | 자원 · 뚝딱  |
| 1 나     12 |                                   | 보정까지     |
| 2        19 |   입구 >--------------------+     | 강화 · 메뉴  |
| 3 역신    8 |        |      6x4 칸        |     | 요청함       |
| 4 다음   14 |        +--------------------<     |              |
| 5 넋      - |                                   |              |
| 6         9 |                                   |              |
| 128x292     | 400x292                           | 112x292      |
+-------------+-----------------------------------+--------------+
| 선택 유닛       [Z 결과] [X 결과] [C 결과]       [상세] 640x44 |
+----------------------------------------------------------------+
```

- 왼쪽 줄은 고개 순서대로 둔다. 역신의 현재·다음 표식만 줄 사이를 옮긴다. 공용 체력은 상단 관문 옆에 둔다. 다섯 사람의 배치를 그리지 않아도 내 차례가 얼마나 남았는지 알 수 있다.
- 지게를 고르고 카드에서 ‘보내기’를 누른 뒤 내 칸에서 보낼 유닛, 왼쪽 줄에서 받을 사람을 고른다. 응답은 오른쪽 요청함에서 한다. 내 넋은 같은 줄에서 생존자를 고른 뒤 아래 ‘토큰 보내기’를 누른다.
- 휴대폰은 상단 24, 본문 298, 카드 48px로 나눈다. 본문 너비를 왼쪽 152, 고개 488, 오른쪽 160px로 잡으면 여섯 줄을 각각 44px로 눌러도 집계 제목 자리가 남는다. 격자와 출입구 위에는 알림을 얹지 않는다.
- 약점은 남의 잡귀가 어디에 몰렸는지 보이지 않는다는 점이다. 직전 라운드 수치만으로는 이번 라운드에 급해진 고개를 고르기 어렵다.

### B. 위쪽 여섯 칸, 고개마다 작은 지도

```text
+----------------------------------------------------------------+
| 라운드 · 시간 · 내 잡귀/한도 · 관문 · 역신 체력          640x24 |
+----------+----------+----------+----------+----------+---------+
| 1 나 12  | 2     19 | 3 역신 8 | 4 다음14 | 5 넋  -  | 6     9 |
| 작은 고리와 잡귀 분포   각 106x28 (양 끝은 108x28)             |
+------------------------------------------------+---------------+
| 내 고개                                        | 뚝딱 · 보정   |
|   입구 >---------------------+                 | 강화 · 메뉴   |
|        |       6x4 칸        |                 | 요청함        |
|        +---------------------<                 |               |
| 480x264                                        | 160x264       |
+------------------------------------------------+---------------+
| 선택 유닛       [Z 결과] [X 결과] [C 결과]       [상세] 640x44 |
+----------------------------------------------------------------+
```

- 여섯 칸마다 직전 라운드 수치와 작은 고리를 둔다. 고리의 네 변은 현재 잡귀가 몰린 쪽을 밝기로 나타낸다. 역신은 그 위의 탈 한 개로, 다음 고개는 테두리의 화살표로 표시한다. 작은 지도는 읽기 전용이다.
- 지게 카드에서 보낼 유닛을 지정하면 오른쪽에 받을 사람 목록이 열린다. 수락·거절도 오른쪽에서 한다. 넋이 되면 같은 목록에서 생존자를 골라 토큰을 보낸다.
- 휴대폰은 위에서부터 상태 24, 지도 띠 32, 본문 270, 카드 44px로 쓴다. 본문은 고개 560, 조작 240px다. 지도에 손을 댈 필요가 없고, 오른쪽 대상 목록은 두 열 세 줄로 펼쳐 44px 버튼을 확보한다.
- 약점은 작은 고리와 숫자를 한 줄에서 같이 읽어야 한다는 점이다. 28px 높이에서는 역신과 잡귀 분포가 겹치기 쉽고, 고리 여섯 개가 계속 변해 내 전투에서 눈길을 뺏는다.

### C. 고개를 골라 크게 보는 관전 전환

```text
+----------------------------------------------------------------+
| 라운드 · 시간 · 내 잡귀/한도 · 관문 · 역신 현재 > 다음   640x24 |
+-----------------------------------------+----------------------+
| 보는 고개 이름                 [내 고개] | 여섯 고개 (직전 R 끝)|
|                                         | [1 나 12] [2     19] |
|   입구 >---------------------+          | [3 탈  8] [4     14] |
|        |       6x4 칸        |          | [5 넋  -] [6      9] |
|        +---------------------<          | 뚝딱 · 보정 · 메뉴   |
| 440x292                                 | 요청함       200x292 |
+-----------------------------------------+----------------------+
| 내 선택 카드 / 관전 중에는 보는 사람 이름과 [내 고개로]  640x44 |
+----------------------------------------------------------------+
```

- 시작 화면은 내 고개다. 오른쪽 고개 버튼을 누르면 같은 크기로 그 사람의 실제 배치를 본다. 역신은 버튼의 탈 표식과 상단 공용 체력으로 추적하고, 보고 있는 고개에 들어오면 고리에서도 보인다. 관전 중에는 배치·조합 입력을 잠그고 내 잡귀 경고와 ‘내 고개로’를 남긴다.
- 지게 카드에서 보낼 유닛을 고른 동안에는 오른쪽 버튼이 ‘받을 고개 선택’으로 바뀐다. 대상을 눌러도 관전으로 넘어가지 않는다. 요청은 오른쪽에서 수락한다. 넋은 관전할 고개를 고른 뒤 하단의 ‘이 고개에 토큰 보내기’를 누른다.
- 휴대폰은 본문 298px를 고개 520, 오른쪽 280px로 나누고 상단 24, 하단 48px를 쓴다. 두 열 세 줄의 고개 버튼과 하단 복귀 버튼을 44px 이상으로 잡는다. 전환은 버튼으로만 한다. 고개 위를 가로로 끌면 유닛이 움직인다.
- 약점은 남의 고개를 보는 동안 내 출입구가 가려진다는 점이다. 역신이 내 고개에 올 때 복귀 버튼을 한 번 더 눌러야 한다.

## 비교와 선택

| 전투 중 할 일 | A · 왼쪽 여섯 줄 | B · 작은 지도 띠 | C · 관전 전환 |
| --- | --- | --- | --- |
| 역신을 따라 내 유닛 옮기기 | 내 고리가 계속 보임 | 내 고리가 계속 보이나 세로 여유가 적음 | 다른 고개를 보던 중이면 복귀 필요 |
| 남은 잡귀 비교·지원 대상 고르기 | 같은 열에서 수치를 읽고 그 줄을 선택 | 지난 집계와 현재 분포를 같이 봄 | 수치를 보고 실제 배치까지 확인 가능 |
| 휴대폰에서 어려운 점 | 양옆 패널 사이에서 시선이 오감 | 작은 지도 여섯 개를 구별해야 함 | 관전과 대상 선택이 같은 버튼을 씀 |

**2단계는 A안으로 시작한다.** 화면에서 가장 자주 번갈아 하는 일은 뽑고, 조합하고, 내 고리에서 자리를 바꾸는 일이다. A안은 뚝딱 버튼 옆에서 남은 뽑기 횟수를 읽고, 유닛을 누른 자리에서 키 하나로 조합하고, 역신이 들어와도 곧바로 끌어 옮길 수 있다. 라운드가 끝나면 왼쪽 숫자 한 열로 여섯 사람의 결과를 비교한다. 첫 6인판에서 확인하려는 뽑기의 손맛, 보스전의 난도, 서로 잡귀 수를 견주는 재미를 기존 조작 위치에서 시험할 수 있다.

## 2단계 명세에 옮길 변경점

- 왼쪽 128px 조합 도우미 자리를 스코어보드로 바꾼다. 도우미와 도감은 메뉴에 합치고 Q로 도우미를 연다.
- 위쪽 24px에는 라운드·내 한도 경고와 관문 진행을 둔다. 가운데는 400×308에서 400×292로 줄인다. 줄어드는 16px는 아래 여백에서 빼서 PC 격자 원점 (232, 114), 32px 칸과 고리 위치를 유지한다.
- 오른쪽 112px에는 소환 횟수·보정과 뚝딱을 붙이고 강화·불 바꾸기는 접는다. 넋 도착 알림과 추후 지게 요청은 이 패널 안에서 받는다.
- 하단 카드는 28px에서 44px로 높인다. 선택 유닛의 즉시 조합 세 자리와 상세를 고정하고, 탈락한 사람에게는 같은 자리에 넋 지원 조작을 둔다.
- PC에서는 기존 중앙 정렬과 배율을 쓴다. 휴대폰에서는 A안의 가용 폭에 맞춰 패널을 배치하고 확대된 칸 위치로 터치를 판정한다. 실기기에서는 출입구 양옆의 칸 교환과 손을 뗀 직후의 조합 버튼 입력을 확인한다.

## 디자이너에게 확인할 점

1. 다른 고개에 이번 라운드 한도 경고가 뜨면, 직전 라운드 수치 옆에 ‘위험’도 표시할까?
2. 역신이 내 고개로 오기 전에는 ‘다음은 내 고개’면 충분한가, 지금 지나고 있는 고리에서 얼마나 돌았는지도 필요한가?
3. 넋으로 지원 대상을 고를 때 여섯 줄의 집계만으로 충분한가, 그때부터는 남의 배치를 크게 볼 수 있어야 하는가?

## 결정 (Claude, 2026-11-21, 사용자 확인 전)

- **A안으로 간다.** 내 고리가 항상 보이고, 지금 조작 위치(뚝딱·카드·Z/X/C)를 그대로 쓸 수 있다.
- **스코어보드는 직전 라운드 수치가 아니라 지금 수치를 보여 준다.** 장르에서 남의 고개가 밀리는 걸 실시간으로 보는 게 협동의 긴장감이고, A안의 약점(이번 라운드에 급해진 고개를 모름)도 이걸로 메운다. 라운드 끝 수치는 결과 화면과 라운드 끝 요약에 따로 남긴다.
