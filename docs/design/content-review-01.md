# 116종 콘텐츠 초안 1차 검토 (Fable)

## 요약

수량·레시피 형태·확정 22종·1등급 양쪽 계열·사용 횟수 규칙은 모두 통과했다. 문제는 물건 선정, 레시피 연결, 6등급 스킬의 개성이다.

## 우선순위 7가지

1. 지어낸 물건명(불씨통, 쑥연통, 물등, 겹지등, 쌍회전등, 고갯지팡이, 나무꾼 짐틀, 밤길 등불, 갯벌 횃대 등)과 물건이 아닌 것(봉화대, 석교받침, 남문 문짝, 장승, 당집 목상, 대들보 등)을 실재 생활 물건으로 바꾼다. 실재 대체어 예: 조족등, 유등, 지겟작대기·물미장, 바지게, 부집게, 인두판, 모깃불. 등 계열 19종과 지게 3종·찧는 도구 7종·솥 5종 중복을 줄이고 풍물(장구·징·꽹과리)·탈·규중칠우·곰방대·요강·바가지로 채운다.
2. 외짝나막신은 짚신 한 짝으로(게다 연상), 갯등대는 제주 도대불로(근대 시설), 장승 유닛은 배경 소품·한도 게이지와 겹치므로 뺀다.
3. 1·2등급이 사용 상한 5회에 꽉 차서 "같은 재료 ×2" 레시피 20개와 억지 연결이 생겼다. 상한을 완화해야 고칠 수 있다.
4. 6등급 스킬 대부분이 "N번째 공격마다 A + B"의 수치 변형이다. 설화 10종은 이야기와 스킬을 맞추고(감투=안 보임, 빚돈=돈), 필요하면 새 효과 한두 개를 정식 제안한다. 말없이 넓힌 발동 조건(처치 시 불길·둔화, 체력 조건부 디버프, 타이머 2개)은 명세에 적는다.
5. 쇠망치(4등급)가 모루를 대체하고 6등급 길달과 차이가 없다. 받는 피해 증가 유닛(6등급 11, 5등급 7)이 많아 상한 +50%에 금방 찬다. 서로 다른 오라 합산 상한이 없어 공속 +95%까지 쌓인다.
6. 군중 제어만 있는 유닛(새끼줄, 엿판, 김서방, 떡판)과 돌물확에 피해 역할을 준다. 공격마다 거는 지속 피해는 갱신 때 남은 피해를 버리므로 표기보다 약하다(조청단지 200% 표기, 실효 약 62%).
7. 흥륜사 오타, 출처 신뢰도를 "원전 확인 / 각편 확인·이름 창작"으로 나누기, 쪽수 인용 4건(김서방, 빚돈, 갯길불, 감투)과 히든 5종 출처 확인, 제목을 「도깨비 랜덤 디펜스」로.

## 연결이 좋은 곳

주마등, 돌확, 약탕기, 떡시루, 떡메, 제주 허벅, 길달, 비형랑(귀교), 천년 떡판, 천년 돌절구.

## 설화 확인

도깨비방망이(나무꾼), 도깨비 씨름, 영감놀이, 삼국유사 도화녀 비형랑은 링크로 확인. 길달은 여우로 변해 달아나다 죽는 결말이라 아군으로 쓸 때 다룰 방법이 필요하다. 두두리의 목상·대추나무 재료는 근거 없는 게임 설정이다.
