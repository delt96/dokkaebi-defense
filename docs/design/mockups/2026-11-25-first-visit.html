Esc: 실패 장면 건너뛰기 → 잠그는 창 → 마지막에 연 창 → 선택 풀기. 5보스 체력 줄임: 저항 줄이 보이는 라운드(60라운드 이후)이거나 잡귀 꼬리 글이 붙는 위험 단계일 때만 "보스 체력 N / M" → "보스 N". 전체 값은 title과 판 위 보스 체력 막대로 볼 수 있습니다. 6'장승 …' 글자 숨김: B3 위험 단계(57~60)에서 잡귀 꼬리 글('· 2마리 남음', 60이면 '· 한계')이 같은 뜻을 더 정확히 말하므로 그동안만 숨기고 게이지(색은 B3 ②)는 남깁니다. 초과(61+)에는 꼬리 글이 없으므로 '장승 무너짐'이 다시 보입니다. ·B3 ⑧ 뒤에는 거절 알림이 버튼 위로 옮겨 가 상단 줄의 .notice 자리는 비어 있다고 보고 계산했습니다(구현 순서 B3 → B4).

8. 지침 대조 (ui-ux-pro-max)

출처: [DB] ux-guidelines.csv 검색, [QR] quick-reference.md, [보충] DB에 맞는 항목이 없어 일반 원칙으로 채운 것. '(직접 검색)'이라 적은 다섯 줄은 브리프에 없어 이 설계에서 직접 찾은 것입니다.

지침지켰는지어떻게 / 예외와 이유
primary-action [QR] 화면마다 주 버튼 하나지킴첫 화면 '방 만들기'만 금색, '혼자 하기'는 같은 크기 보조. 초대 화면 '입장하기'. 대기실 방장 '시작', 손님 '준비'(준비 뒤에는 보조 모양). 메뉴 창은 주 버튼 없이 같은 무게 둘(어느 쪽도 권하지 않음).
progressive-disclosure [QR] · User Freedom [DB]지킴'처음이라면'은 접기. 첫 판 안내는 창이 아니라 줄 앞 한 마디라 건너뛸 필요가 없고, 설정 '도움말'로 끌 수 있음. 강제 투어 없음. 세로 안내에는 '이대로 보기'.
Confirmation Dialogs [DB] · destructive-emphasis [QR]지킴솔로 '다시 시작'·'처음 화면으로'는 확인 창, 위험 단추는 .danger 색 + 동작 이름. 초점은 '취소'.
Confirmation Dialogs [DB] · 대기실 나가기예외확인 창 없음. 시작 전이라 링크로 다시 들어올 수 있고 잃는 것이 없음. 대신 끝난 뒤 짧은 알림 "방을 나왔습니다"(4초). 혼자 있는 방장이 나가면 방이 닫혀 링크가 죽지만 새로 만들면 되므로 확인을 두지 않음(문서 질문 6).
Empty States [DB]지킴첫 판 유닛 0개면 ① "Space나 뚝딱!으로 유닛을 뽑으세요 (도깨비불 N개)". 조합할 것이 없으면 ②′ "조합할 재료가 아직 모자랍니다 · Space로 더 뽑으세요".
Target Size (Minimum) [DB] 24×24지킴배율 1 기준: 첫 화면 버튼 44px, '처음이라면' 머리 28px, 난이도 단추 28px, '처음 화면으로' 링크 24px 이상, 대기실 '나가기' 38px, 메뉴 창·확인 창 단추 24px, 세로 안내 단추 44px. 상단 '메뉴'는 22px 높이지만 간격으로 같은 효과(위 1번 설명). 톱니(18px)는 B4가 바꾸지 않음(A줄).
Touch Spacing [DB] 8px지킴두 버튼 사이 8px, 대기실 '링크 복사'↔'나가기' 8px(지금 6px에서 넓힘), 메뉴 창 단추 사이 8px, 상단 톱니↔메뉴 8px. 난이도 단추 사이는 4px(지금 3px)로 8px가 안 됨: 단추가 28px라 24px 원끼리 겹치지 않음.
Focus Appearance [DB] 2px·3:1지킴메뉴 창·확인 창 단추와 '처음이라면' 머리, 두 버튼: 2px 금색(--accent #ffe08a) 둘레, 2px 띄움. 판(#17121f)·바깥 바탕(#0d0a14)과 대비 3:1 넘음. DOM 단추·창 초점을 금색으로 하는 것은 B1~B4 공통 규칙(크림 --ink는 판 위 표시에만).
Focus Not Obscured [DB]지킴메뉴·확인 창(5층)·세로 안내(8층)가 뜨면 B2 판 안 기둥 창·판 밖 창(2·3층)은 inert로 그 아래에 그려 초점 요소를 덮지 않음.
Stacking Context · Z-Index Management [DB] (직접 검색)지킴층 번호는 B2 ⑰ 표 하나(1~8층)만 따르고 B4는 새 번호를 만들지 않음. 메뉴·확인 창 5층, 세로 안내 8층. P 멈춤 덮개(4층) 위에 메뉴가 옴(5번 ④). 실패 장면이 열린 잠그는 창을 닫을 때 그 안의 초점은 푼다 [보충: DB에 맞는 항목 없음].
Content Jumping [DB]지킴'처음이라면' 첫 상태는 첫 그리기 전에 정함(접혔다 펼쳐지는 깜빡임 없음). 펼침은 누른 사람이 일으킨 변화라 아래가 밀리는 것을 받아들임. 대기실 안내 줄은 글이 없을 때도 자리를 비워 둠. 하단 안내 줄은 높이 고정(28px), 한 마디가 바뀌어도 줄 높이 그대로. 나온 뒤 알림은 흐름 밖.
orientation-support [QR]지킴세로 안내는 판 화면에서만, '이대로 보기'로 계속 볼 수 있음. 바깥 화면은 세로에서도 360px 상자로 읽힘.
Color Only [DB]지킴안내 한 마디는 금색이지만 문장 자체가 뜻. 대기실 준비 상태는 '준비/대기' 글자. 위험 단추는 글자로 동작을 말함. 상단 꼬리 글은 B3 규칙(색 + 크기 + 글).
글자 크기 [DB Readable Font Size] 새 글자 10px 이상, 핵심 수치 12px 이상일부 예외판 안 새 글자: 안내 한 마디 11px, 메뉴 단추·확인 문구 11px, 메뉴 제목 12px. 난이도 설명(판 길이)은 11 → 12px. 예외: 안내 한 마디 속 '지금 14마리'는 11px — 같은 숫자가 상단 줄에 12~13px로 있어(B3 ①) 여기서는 보조 표시. 9px 이하 새 글자 없음.
Reduced Motion [DB]해당 거의 없음B4는 새 움직임을 넣지 않음: '처음이라면' 펼침·세로 안내·메뉴 창 모두 바로 나타남. 알림 "방을 나왔습니다"도 서서히 사라지게 하지 않고 4초 뒤 바로 사라짐.
Toast Notifications [DB] 3~5초지킴"방을 나왔습니다" 4초.
Contextual Live Badge Updates [DB]지킴안내 한 마디는 aria-live로 만들지 않음. 판 알림은 B3이 정한 한 곳만 읽힘(다투지 않게).
이모지를 아이콘으로 쓰지 않기 (브리프 1절 점검표)지킴'처음이라면' 펼침 표시는 CSS 삼각형, 톱니는 지금 SVG 그대로. 목업의 '▸ 음악 출처'는 지금 화면 글자를 옮긴 것.
Disabled States [DB] (직접 검색)지킴대기실 '시작'이 꺼진 동안 흐리게 + 커서 금지 + 바로 아래 안내 줄이 이유("모두 준비하면 시작할 수 있습니다 · 0/1명 준비").
Consistent Help [DB] (직접 검색)지킴'처음이라면'은 첫 화면·초대 화면 모두 소개 바로 아래 같은 자리.
Essential Text Truncation · Compact Label Overflow [DB] (직접 검색)지킴상단 줄은 넘치지 않게 줄이는 순서를 정함(보스 체력 "N / M" → "N", 위험 단계에서 '장승' 글자 숨김). 줄인 값의 전체는 title과 판 위 보스 막대에서 볼 수 있음. 하단 줄은 한 마디가 맨 앞이라 잘리지 않음.
