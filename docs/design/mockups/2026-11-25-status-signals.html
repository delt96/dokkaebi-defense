Color Only [DB]지킴단계마다 색 + 글자(· 주의 / · N마리 남음 / · 한계 / · 초과) + 숫자 크기. 끊김은 점선 테두리 + "끊김" 글. 탈락은 "넋" 글 + 흐림. 당첨은 노란 둥근 고리 + "6등급!" 글이고 B1 판 표시는 크림 꺾쇠라 색과 모양 둘 다로 갈린다. 가장자리 물듦·장승 색은 같은 정보를 HUD 글이 함께 알린다.
