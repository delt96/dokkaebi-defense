# 샘플 스프라이트 1차 검수 (Fable)

2026-11-20. 대상: `art/samples/` 솥뚜껑(1등급), 빗자루(2등급), 잡귀, 밤 배경 합성. 검수자에게는 메인 세션이 찾은 문제를 알려주지 않고 백지에서 보게 했다. 좌표는 8배 이미지(256×256) 기준 눈대중.

## 전체 인상

- 익살스러운 유닛: 전달됨. 솥뚜껑의 벌어진 눈, 빗자루의 볼터치.
- 으스스한 세계: 약함. 배경은 어둡기만 하고 도깨비불이 광원이라는 설정이 그림에 없음 (불꽃이 몸통·바닥을 비추지 않음).
- 한국적인 느낌: 거의 없음. 솥뚜껑은 호출벨·UFO, 빗자루는 짚더미·주먹밥, 잡귀는 팩맨 유령으로 읽힘.
- 쓰쿠모가미와 차별화: 안 됨. "물건 + 점 눈 + 볼터치 + 짧은 다리"는 일본 마스코트 문법.

## 스프라이트별

### 솥뚜껑
- 좋음: 넓은 실루엣이 1배에서도 덩어리로 읽힘. 불꽃 심지가 1배에서도 보임.
- 받침판(y 198~215)이 돔보다 넓어 종·모자로 보임 → 판 제거, 돔 가장자리가 테두리. 돔 꼭대기를 y 115쯤으로 낮춰 납작하게.
- 꼭지(x 100~155, y 75~100)가 굴뚝 같음 → 위가 넓은 버섯형 손잡이.
- 푸른 회색이라 밤 배경·파란 불꽃에 묻힘 → 따뜻한 검회색(#3a3436 계열) + 녹슨 갈색 중간톤.
- 좌상단 하이라이트가 불꽃 위치와 안 맞음 → 꼭지 주변·돔 윗선에 불꽃색 띠 1~2px.
- 다리가 1배에서 안 보이고 빗자루엔 다리가 없음 → 다리 유무 규칙 통일.

### 빗자루
- 좋음: 황토색이 밤 배경에서 가장 잘 뜸. 1배 가독성 최고.
- 자루가 6px로 너무 짧고 불꽃이 끝에 붙어 촛불·성냥처럼 보임.
- 좌우대칭 삼각형이라 짚더미 같음 → 묶음 아래를 좁히고 아래로 한쪽으로 휘어 퍼지게 (닳은 몽당빗자루).
- 몸통에 어두운 세로 결 3~4줄, 밑단 외곽 들쭉날쭉하게.
- 붉은 띠 한 줄이 모자 띠 같음 → 가는 끈 2~3줄, 색은 쪽빛이나 탁한 주황. 채도 높은 빨강은 잡귀 눈 전용.
- 초록 불꽃이 파란 불꽃보다 작음 → 등급 표시는 크기 통일.

### 잡귀
- 좋음: 붉은 눈과 이빨은 확대 시 위협감 있음.
- 1배에서 몸통이 배경에 녹아 빨간 점 두 개만 남음.
- 몸통을 밝히지 말고 윗 윤곽 안쪽 1px에 차가운 연보라(#7a6a9a 계열) 띠. 검은 외곽선은 빼거나 배경보다 밝게.
- 둥근 돔 + 물결 밑단은 흔한 유령 → 산발 머리카락 가닥 2~3px, 비대칭, 길이가 다른 아랫단 가닥.

## 한 화면에 수십 개가 섞일 때

- 등급 구분이 8×8px 불꽃 색뿐 → 6등급이면 파랑·초록·청록이 헷갈리고 색약 사용자는 구분 불가. 불꽃 갈래 수·크기 같은 모양 차이를 함께.
- 불꽃은 모양·크기·높이를 한 틀로 통일하고 별도 레이어로 두어 코드에서 색 교체·흔들기.
- "따뜻하고 밝은 유닛 대 차갑고 어두운 잡귀" 구도가 빗자루에서만 성립 → 유닛 몸통은 모두 중간 명도 이상.
- 배경 체커 디더가 1배에서 노이즈 → 유닛 서는 구역은 단색에 가깝게.
- 외곽선 색이 제각각이고 밤 배경에서 기능을 잃음 → 분리는 몸통 명도와 불꽃 광원(코드로 넣는 반투명 빛 원)으로.
- 불꽃이 위 8~9px을 차지해 몸통 높이 20px 남짓. 폭도 31px·22px로 차이가 큼.

## 한국색 보강

- 표정: 점 눈·볼터치 대신 하회탈식 초승달 눈웃음이나 장승의 퉁방울눈.
- 색: 황토, 옹기 갈색, 쪽빛, 단청 녹색·주홍 같은 재료색 팔레트를 먼저 정함.
- 소품: 새끼줄(금줄), 헝겊 조각, 땜질 자국 같은 오래 쓴 흔적을 물건마다 하나씩.
- 뿔: 넣지 않는 편이 안전. 뿔 달린 도깨비는 일본 오니 이미지라는 지적이 많음.

## 32px 대 48px

일반 유닛과 잡귀는 32px 유지 권장.
- 지금 문제는 해상도가 아니라 형태 설계와 명도.
- 수십~수백 개가 나오는 화면엔 단순한 덩어리가 유리하고 제작량도 감당하기 쉬움.
- 화면엔 정수 2배(64px) 표시를 기본으로.
- 최상위 두 등급의 큰 도깨비와 보스만 48px 또는 64px 캔버스로 따로.

## 우선 수정 순위 (검수자 제안)

1. 잡귀 배경 분리: 윗 윤곽 연보라 띠, 검은 외곽선 제거, 비대칭 산발 실루엣
2. 솥뚜껑 재설계: 받침판 제거, 납작한 돔, 버섯형 꼭지, 따뜻한 무쇠색
3. 불꽃 규격 통일: 같은 크기·위치, 별도 레이어, 등급별 모양 차이, 몸통 윗면 불꽃색 띠
4. 빗자루 형태: 한쪽으로 휜 솔, 세로 결, 끈 2~3줄, 띠 빨강 제거
5. 공통 규칙 문서화: 팔레트, 얼굴 문법(탈 눈매), 다리 유무, 몸통 점유 크기를 정한 뒤 다음 유닛
