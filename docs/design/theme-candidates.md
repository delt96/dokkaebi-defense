# 세계관 후보 상세

2026-11-20. 메인 설계 문서 4장의 부록. 후보 1~6은 Fable 서브에이전트 제안(제 후보를 알려주지 않고 따로 받음), 후보 7은 메인 세션 제안.

유닛 수 가정: 6등급 56종 (20/14/10/6/4/2).

## 1. 묵은 것들 (도깨비)

- 설정·톤: 오래 쓴 물건에 도깨비불이 붙으면 도깨비가 된다. 여섯 고개 마을의 헌 물건들이 밤마다 넘어오는 잡귀를 막는다. 익살스럽고 약간 으스스하다.
- 소환: 도깨비방망이 "뚝딱". 헛간의 헌 물건에 불이 붙어 눈을 뜬다. 불꽃 색(등급 예고)이 먼저, 물건 실루엣(정체)이 나중에 나오는 두 박자 연출.
- 조합: 도깨비불을 한 물건에 몰아 준다. 하위 2~3개의 불이 합쳐지고, 불이 클수록 더 오래 묵은 물건이 깨어난다.
- 등급: 불꽃 색(푸름 → 초록 → 보라 → 붉음 → 금 → 흰색) + 뿔 개수. 최상위 두 등급만 큰 도깨비 전신.
- 적·보스: 잡귀, 역귀, 그슨대 같은 그림자형. 10라운드 보스는 불가사리, 강철이, 지네각시 등 민담 요괴. 공유 보스는 당산나무를 노리는 큰 역신, 단계마다 탈이 바뀜.
- 6라인: 마을로 들어오는 여섯 고개. 잡귀가 서낭당을 탑돌이하듯 돈다.
- 공유 숫자: "우리 고개 잡귀 7"
- 재미 축: 뽑기(가장 강함), 요괴 보스로 클리어 쾌감
- 아트: 정물 몸통(빗자루, 짚신, 솥뚜껑, 장독, 키, 부지깽이) + 공통 눈·팔다리·뿔·불꽃 레이어. 32px에서도 실루엣 구분 쉬움. 몹은 그림자 실루엣 팔레트 교체.
- 위험: 정물 공격 동작이 밋밋함 → 투사체·이펙트로 보완. 일본 쓰쿠모가미와 겹침 → 물건·복식·색을 한국 것으로. 해외 유저에겐 도깨비 설명 필요.
- 제목 가안: 「묵은 것들」, 「여섯 고개 도깨비」

## 2. 한 몸 (면역계)

- 설정·톤: 6명이 한 사람 몸속 여섯 장기의 면역계. 귀엽고 깔끔한 과학 그림책.
- 소환: 골수에서 미분화 세포가 분열하다 색이 정해지며 정체 공개.
- 조합: 세포 융합과 분화. 실제 생물학 현상이라 설명이 필요 없음.
- 등급: 핵 개수, 세포막 두께, 발광 테두리, 상위는 섬모·촉수·항체 고리.
- 적·보스: 세균, 바이러스, 기생충. 보스는 내성균, 종양. 공유 보스는 패혈증, 단계마다 변이.
- 6라인: 심장, 폐, 간, 위, 장, 뇌. 순환 이유 = 혈액 순환. 탈락 = 장기 부전.
- 공유 숫자: "간 감염 수치 12" (검사 결과지 UI)
- 재미 축: 몹 수 공유
- 아트: 가장 쌈. 원형 몸통 + 핵·눈·부속물.
- 위험: 전부 동그래서 캐릭터 매력과 뽑는 쾌감이 약함. 의인화하면 「일하는 세포」와 닮음. 질병 소재 톤 관리.
- 제목 가안: 「한 몸」, 「면역 6」

## 3. 결재 뺑뺑이 (사무실)

- 설정·톤: 여섯 부서가 쏟아지는 업무를 막는 회사. 블랙 유머.
- 소환: 채용. 이력서 봉투에서 사원증, 줄 색이 등급 예고.
- 조합: 인턴 셋을 갈아 넣어 대리 한 명.
- 등급: 인턴 → 사원 → 대리 → 과장 → 부장 → 임원. 사원증 줄, 넥타이, 의자, 소품.
- 적·보스: 서류, 메일, 티켓, 민원 전화. 보스는 분기 마감, 감사, 진상 고객. 공유 보스는 전사 장애.
- 6라인: 여섯 부서. 반려된 결재가 계속 도는 게 순환 이유. 탈락 = 번아웃.
- 공유 숫자: "우리 팀 밀린 업무 9건"
- 재미 축: 몹 수 공유, 웹 첫인상
- 아트: 사람 몸통 하나 + 머리·표정·소품. 직군별 소품 없으면 구분 안 됨.
- 위험: 전투가 밋밋함. 직장 유머는 50분 동안 물릴 수 있음.
- 제목 가안: 「결재 뺑뺑이」, 「갈아 넣기」

## 4. 여섯 등대 (별자리)

- 설정·톤: 꺼져 가는 밤하늘, 여섯 등대지기가 떨어지는 별을 주워 별자리를 잇는다. 고요하고 비장함.
- 소환: 별똥별. 꼬리 색·길이로 등급 예고, 착지 후 공개.
- 조합: 별 2~3개를 이어 별자리, 상위는 별자리 짐승·인물이 실체로.
- 등급: 별 개수와 광도. 하위는 점과 선, 상위는 채워진 형상.
- 적·보스: 빛을 먹는 그림자, 혜성 조각. 보스는 일식, 검은 별. 공유 보스는 별자리를 삼키는 공허.
- 6라인: 육각형 배치의 등대 여섯, 몹이 등대 궤도를 공전.
- 공유 숫자: "내 하늘 그림자 5"
- 아트: 하위는 거의 공짜, 검은 배경 발광 픽셀. 상위 20종은 개별 작업.
- 위험: 하위 유닛 애착 약함. 황도 12궁은 식상 → 28수나 창작 별자리. 어두운 화면 가독성.
- 제목 가안: 「여섯 등대」, 「별을 잇는 밤」

## 5. 뼈 맞추기 (묘지기)

- 설정·톤: 묘지기가 도굴꾼과 성물 사냥꾼으로부터 여섯 묘역을 지킨다. 어둡지만 해골 몸 개그.
- 소환: 삽으로 무덤을 판다. 관 재질(나무, 돌, 금)이 등급 예고.
- 조합: 뼈 맞추기. 해골 둘 → 팔 넷 달린 해골. 조합 납득감 최고.
- 등급: 뼈 색, 눈구멍 불빛, 팔·머리 개수.
- 적·보스: 도굴꾼, 용병, 사제. 보스는 성기사, 심문관. 공유 보스는 공성 행렬.
- 6라인: 여섯 묘역, 침입자가 출구를 못 찾고 헤맴.
- 공유 숫자: "우리 묘역 도굴꾼 8"
- 아트: 뼈가 문자 그대로 모듈, 조립 스크립트로 생성 가능. 적이 사람이라 적 아트 비용은 높음.
- 위험: 흔한 소재, 해골 머지 모바일 게임 존재, 화면이 단색.
- 제목 가안: 「뼈 맞추기」, 「여섯 번째 묘역」

## 6. 캡슐 수비대 (장난감)

- 설정·톤: 캡슐 뽑기 기계에서 나온 장난감들이 밤마다 아이 방을 악몽에게서 지킨다. 귀엽고 향수.
- 소환: 동전, 손잡이, 캡슐이 굴러 나와 열림. 뽑기 UI = 세계관.
- 조합: 블록 끼우기, 로봇 합체.
- 등급: 재질(종이 → 플라스틱 → 양철 → 크롬 → 금도금 → 야광).
- 적·보스: 먼지 뭉치, 양말 괴물, 옷장 그림자. 보스는 침대 밑 괴물.
- 6라인: 한 집의 여섯 방, 장난감 기차 레일을 따라 돎.
- 공유 숫자: "내 방 악몽 6"
- 아트: 계열 내 파츠 공유, 계열 간은 거의 안 됨. 중간.
- 위험: 「토이 스토리」와 닮아 보임, 특정 완구 브랜드 형태 회피 필요.
- 제목 가안: 「캡슐 수비대」, 「백 원의 기적」

## 7. 연금술 공방 (메인 세션 제안)

- 설정·톤: 견습 연금술사 6명이 폭주한 실험체로부터 공방을 지킨다.
- 소환: 플라스크에서 호문쿨루스.
- 조합: 합성, 결과물이 재료 생물의 특징을 물려받음 (불도마뱀 + 박쥐 = 불꽃 날개 박쥐). 외형으로 레시피를 짐작할 수 있음.
- 적·보스: 오염된 실험체, 보스는 거대 폭주 실험체.
- 아트: 낮음~중간. 합성 결과 = 재료 파츠 조합이라 시스템과 아트 제작이 같은 구조.
- 위험: 키메라 디자인이 조잡해질 수 있음. 순환 이유와 공유 숫자 이름은 아직 약함.

## 섞기 아이디어 (Fable 제안)

- 묵은 것들 + 한 몸의 구조: 여섯 고개를 한 마을의 여섯 방위로, 가운데 당산나무를 공유 체력처럼. 한 고개가 뚫리면 마을 전체가 위험해져 협동 근거가 생김.
- 묵은 것들 + 여섯 등대의 시각 규칙: 도깨비불을 유일한 광원으로, 배경은 밤 고정. 등급 = 광량. 배경 작업량이 줄고 불꽃 색으로 라인 전력이 읽힘.
- 묵은 것들 + 결재 뺑뺑이의 말투: 유닛 설명문과 공유 문구만 건조한 사무실식 유머. 예: "솥뚜껑, 경력 120년, 잡귀 처리 실적 우수".
