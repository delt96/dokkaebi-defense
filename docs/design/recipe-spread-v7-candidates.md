### 전체 판 봇 (보통·어려움)

실행 명령(둘을 함께 돌렸고 각각 약 7분 걸렸다):

- 보통: `npm run sim -- --stage 3 --check grade6 --defeat on --difficulty normal --seeds 20 --out sim-out/v7-base-normal`
- 어려움: `npm run sim -- --stage 3 --check grade6 --defeat on --difficulty hard --seeds 20 --out sim-out/v7-base-hard`

Task 10 비교 스크립트가 읽을 CSV는 아래 네 개다(저장소 루트 기준). 같은 폴더의 `-yeoksin.csv`는 역신 관문 기록이다.

- `packages/sim/sim-out/v7-base-normal/econ-target-m1-q4-t1-j1-defeat.csv`
- `packages/sim/sim-out/v7-base-normal/econ-switch-m1-q4-t1-j1-defeat.csv`
- `packages/sim/sim-out/v7-base-hard/econ-target-m1-q4-t1-j1-defeat.csv`
- `packages/sim/sim-out/v7-base-hard/econ-switch-m1-q4-t1-j1-defeat.csv`
