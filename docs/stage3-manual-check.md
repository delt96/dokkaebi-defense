# 60라운드 두 창 점검

1. 저장소 루트에서 PowerShell 두 개를 연다. 첫 창에서 아래 서버 명령을, 둘째 창에서 클라이언트 명령을 실행한다.

   ```powershell
   $env:PORT='2577'
   $env:DORANDI_DEV='1'
   npm run start -w @dorandi/server
   ```

   ```powershell
   $env:VITE_SERVER_URL='http://localhost:2577'
   npm run dev -w @dorandi/client -- --port 5183 --strictPort
   ```

2. 일반 창에서 `http://localhost:5183/`로 방을 만들고 시크릿 창에 방 링크를 붙여 넣는다. 서로 다른 이름으로 입장한다. 한 명이 준비한 상태에서 방장이 **60라운드 (시험판)**를 누른다. 두 창의 판 길이와 준비 해제를 확인하고 둘 다 준비한 뒤 시작한다.
3. **장터와 조합.** B로 장터를 열고 소환권을 엽전으로 바꾼다. 빈칸을 남겨 두고 보따리와 단지를 사서 잔액·남은 횟수·결과를 확인한다. Q로 도우미를 열어 재료가 모인 조합의 비용을 보고, 자원이 부족할 때는 상세 카드의 부족량과 비교한다.
4. **퀘스트.** 12라운드 시작 직후 임무에 입장해 처치 수를 본다. 21~29라운드에는 수집과 팀 처치 진행도를 두 창에서 비교한다. 32라운드 씨름과 43라운드 그림자는 등장 시간과 처치 뒤 보상을 확인한다. 20·40·50라운드 보스 처치 뒤 유닛 보상도 확인한다.
5. **설화 의뢰.** B → 의뢰 → 도감에서 일반 6등급 목표를 고른다. 28·29라운드 종료 때 같은 재료 하나만 빠진 상태를 유지하고 31라운드 제안을 확인한다. 두 번째 기회는 44·45라운드 기록과 46라운드 제안이다. 제안이 오면 잡귀 수·비용·지원 한도를 확인하고 라운드 정산까지 재료를 유지한다.
6. **지게 배달.** 보따리에서 지게를 얻으면 보낼 유닛을 선택하고 장터에서 동료를 고른다. 받는 쪽은 빈칸을 찍고 제한 시간 안에 받는다. 양쪽 판의 유닛과 보상, 재사용 대기를 확인한다. 다음 제안은 사양하거나 시간을 넘겨 보낸 쪽에 유닛이 남는지 본다.
7. **길들이기.** 20라운드 강철이의 체력을 낮추고 둔화를 건다. 빈칸과 묵을 마련해 상단 조건이 모두 충족될 때 T를 누른다. 재화 차감, 적 제거, 숨은 유닛 배치를 확인한다.
8. **팀 결과.** 마지막 라운드에서 두 명 모두 메뉴로 포기하면 전멸 결과가 뜬다. 각자 자기 줄을 눌러 그래프의 마지막 눈금과 탈락 라운드를 확인한다. 창 크기를 640×360, 960×540, 1280×720으로 바꿔 본다.

개발 점프는 **방을 만들기 전** 주소 끝에 붙인다. 예를 들어 `/?dev=jump10090`은 12라운드, `/?dev=jump16490`은 20라운드, `/?dev=jump36990`은 43라운드 시작 직전이다. 60라운드 결과를 볼 때는 `/?dev=jump51300`으로 60라운드 시작 틱에 맞춘다. 새 방마다 판 길이를 다시 고른다. 점프는 빈 전투로에서 시작하므로 지게 획득과 설화 재료 기록은 직접 쌓아야 한다.
