## 1. 등급 체계

### 1.1 등급 인코딩 [확인]
- **이름 접미사**: `Name=<캐릭터명> <수식어> - <등급>`. 등급 단어가 마지막 ` - ` 뒤에 붙는다.
- **색상 코드**: 같은 등급은 같은 `|cffRRGGBB`를 쓴다(아래 표).
- **유닛 툴팁(Tip/Ubertip)은 모두 비어 있다** (`Ubertip=,`). 등급과 레시피 정보는 유닛이 아니라 **조합 능력의 Ubertip**에 있다.
- 히든 등급은 접미사 없이 `[히든조합]` 접두어와 색 `db7093`으로 표시한다.
- 영원한 등급은 이름 전체를 `FFFA78`로 칠하고 등급어만 `C15AF4` 그라데이션 계열로 칠한다.
- 영웅(H)은 `Name`에 칭호를, `Propernames`에 "이름 - 등급"을 넣는다.

- 공격타입은 normal / pierce / siege가 대략 1/3씩이다. hero("패기")는 희귀 이상에서만 나오고 불멸/영원에서 비중이 커진다. **magic과 chaos는 0개다.**
- 플레이어 유닛 HP는 10(무적이라 무의미)이다. 일부 유닛의 HP·마나는 스킬 자원으로 쓰인다(§4).

### 3.2 형태 요약 (디자인용)
```
흔함 ×2                      → 안흔함
(안흔함 ×2 + 흔함) ≈ 흔함 5개  → 특별함
특별함 ×3                     → 희귀함        (≈ 흔함 15개 상당)
희귀함 ×3 + 목재 3            → 전설적인      (≈ 흔함 45개 + 목재 3)
전설 1~2 + (히든/변화/희귀) + 5000골드 + 목재 5      → 제한됨
랜덤전용 + 토큰 + 상위 2~3 + 10000골드 + 목재 7     → 신비함
```
1단계 위로 올라갈 때마다 재료가 3배, 공격력은 5~10배가 된다. 그래서 조합이 언제나 이득이다. 전설부터는 목재가 병목 자원이다.

## 4. 플레이어 유닛 스킬 원형

스킬 툴팁은 정형화되어 있다: `◎발동조건 : 공격시 N% 확률` / `◎범위 : N` / `◎데미지 : N만 마법데미지` / `◎추가효과 : N초 스턴`.
베이스 능력은 `AHbh`(Bash) 311개를 **툴팁 홀더**로 쓰고 실제 효과는 스크립트와 더미 유닛이 낸다. **[추정]** `AHbh`는 0% 확률로 둔 표시용이다.

### 4.1 발동 방식 (능력 수 기준) [확인: 툴팁 키워드]

| 발동 | 의미 | 분포 |
|---|---|---|
| 공격 시 N% 확률 | 주력 방식 | 특별 18 → 희귀 41 → 전설 50 → 영원 27 |
| 마나 N 도달 시 자동 | "마나 스킬". 희귀 이하에는 없음 | 전설 6, 히든 10, 불멸 7, 신비 12, 영원 6 |
| 체력 N 소모 | 무적 유닛의 HP를 스킬 자원으로 사용(자연회복 + 공격시 회복) | 전설 4, 불멸 6, 신비 5 |
| 액티브(쿨타임/사용효과) | 소수 | 등급당 2~8 |
| 패시브/오라 | 상시 | 전 등급 |

## 9. 6인 웹 랜덤 디펜스에 옮길 구조 (설계 시사점) [추정/제안]

1. **등급 사다리**: 기본 5단(흔함 → 안흔함 → 특별 → 희귀 → 전설) + 사이드 등급(히든, 변화)을 두고, 엔드게임 등급은 2~3개면 충분하다. 원본은 등급이 14개라 상위가 서로 겹친다(DPS 중앙 4~12만대에 몰림).
2. **조합 비율**: 하위 2~3개 → 상위 1개. 상위로 갈수록 "같은 등급 3개"를 고정하고, 전설부터 2차 자원(목재)을 요구한다. 최상위는 크로스 재료(랜덤 전용 + 토큰)로 운 요소를 섞는다.
3. **공격력 배수**: 단계당 ×5~10, 엔드게임은 ×1.5~2 + 스킬로 차별화.
4. **판매 → 소환권 환원**: 실패한 운을 회수하는 장치. 등급별 위습 0.33 / 0.5 / 1 / 2.
5. **3각 상성 + 만능 1종**: 웨이브 / 보스 / 건물에 각각 다른 방어타입을 줘서 덱 다양성을 강제한다.
6. **방어 공식**: 낮은 계수(0.02)와 보스 방어 100~400을 조합해 방깎 스킬과 오라에 전략 가치를 만든다.
7. **스킬 표준 템플릿**: 발동조건(공격시 N% / 마나 N / 체력 N) · 범위 · 데미지 · 추가효과(스턴 s, 둔화 %, 방깎). 등급별 수치는 §4.3을 기준값으로 쓴다.
8. **업그레이드 2축**: 등급별(20레벨, 저비용, 고성장) × 공격타입별(3레벨, 고비용 + 목재).
