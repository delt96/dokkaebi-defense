# 60라운드 경제 개편 Implementation Plan

> For agentic workers: implement task-by-task with TDD; steps use checkbox (- [ ]) syntax.

**Goal** — 새 60라운드 판에서 고정 확률 장터와 지게 교환으로 조합 재료를 구하고, 체력에 따라 길들이기를 시도해 전용 조합을 완성하고 왼쪽 퀘스트 칸에서 진행 상황을 확인하게 한다.

**Architecture** — Lane commands settle purchases and exchanges in order against the authoritative inventory. Solo reads the lane projection directly, while RoomCore streams the same projection with seat-specific quest outcomes and acknowledgements. Clients keep selection, filters and scroll position locally and resolve names and skills against the room's version of the unit catalogue.

**Tech Stack** — TypeScript, npm workspaces, Vitest/happy-dom, Phaser, Colyseus RoomCore, tsx simulator.

**Spec:** `docs/superpowers/specs/2026-11-21-stage3-economy-simplify-design.md` (same revision as this plan).
