# 70라운드 개편 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 3단계 판을 60라운드에서 70라운드로 늘리고(한 판 약 44분 유지), 65라운드부터 몹을 세게, 65~69에 5번째 역신을 넣는다.

**Architecture:** 대부분 데이터(`packages/logic/data/stage3/*.json`) 변경이다. 로직은 두 곳만 바뀐다. 하나는 체력 공식에 65라운드부터 붙는 배수(`balance.hp.late`)이고, 다른 하나는 '3단계인가'를 `rounds === 60`으로 묻던 코드를 지우는 것이다. 수치는 시뮬레이터(`--set`)로 맞춘 뒤 JSON에 넣는다.

**Tech Stack:** TypeScript, vitest, npm workspaces (`@dorandi/logic`, `client`, `server`, `sim`)

**Spec:** `docs/superpowers/specs/2026-11-23-rounds-70-design.md`

## Global Constraints

- 브랜치 `rounds-70`(메인 checkout). 커밋은 해도 되고 push·main 병합은 하지 않는다.
- 1~60라운드의 이벤트 위치(장터·사냥·역신 1~4·씨름·그림자·드롭)는 바꾸지 않는다.
- 20라운드 판(stage1·stage2 데이터)은 그대로다.
- 시간: `prepSeconds` 15, `roundSeconds` 34, `bossRoundSeconds` 70. 시뮬레이터에서 초반 기준이 깨질 때만 35/65로 바꾼다.
- 주석은 영어로, 코드만 봐서 알 수 없는 것만 단다. 커밋 메시지는 영어로 쓰고 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`로 끝낸다.
- `npm install`이 `package-lock.json`을 바꾸면(pixelfx https → ssh) `git checkout package-lock.json`으로 되돌린다.

## Review Focus

1. **경제 없이 돌리는 3단계 데이터**(`stripEconomy`, 시뮬레이터 기본): 검증과 장터 판별을 바꾼 뒤에도 오류 없이 불러와져야 한다. → Task 1 시험
2. **보스·이벤트 적의 고정 체력:** 65라운드 배수는 일반 몹에만 붙는다. 보스(`hp` 고정), 사냥·씨름·그림자 이벤트 적, 역신은 그대로다. → Task 2 시험
3. **6인 미만 방의 역신 5:** `startIndex: 4`는 `ring.length`로 나눈 나머지를 쓴다. 2인 방에서도 시작 자리가 있어야 한다. → Task 3 시험
4. **옛 솔로 링크 `?rounds=60`:** 계속 3단계를 연다. → Task 4 시험
5. **70라운드 끝:** 70라운드 보스를 잡으면 클리어, 70라운드 끝 틱에 판이 끝난다(60에서 끝나지 않는다). → Task 2 시험

**Interfaces:**

- Produces: `enemyHp(def, round, b)`. 일반 몹 체력은 `round >= late.fromRound`일 때 `× (1 + perRound × (round − fromRound + 1))`이다. 반올림은 배수를 곱한 뒤 한 번만 한다.

- [ ] **Step 1: 실패하는 시험 작성**

```ts
test('normal enemies grow 8% a round from round 65; bosses and events keep their hp', () => {
  const b = d3.balance; const japgwi = enemyDef(d3, 'japgwi');
  const plain = (r: number) => Math.round((b.hp.base + b.hp.coef * r ** b.hp.exp) * japgwi.hpMult);
  expect(enemyHp(japgwi, 64, b)).toBe(plain(64));
  expect(enemyHp(japgwi, 65, b)).toBe(Math.round((b.hp.base + b.hp.coef * 65 ** b.hp.exp) * japgwi.hpMult * 1.08));
  expect(enemyHp(japgwi, 70, b)).toBe(Math.round((b.hp.base + b.hp.coef * 70 ** b.hp.exp) * japgwi.hpMult * 1.48));
  expect(enemyHp(enemyDef(d3, 'jinegaksi7'), 70, b)).toBe(enemyDef(d3, 'jinegaksi7').hp);
});
test('the match runs 70 rounds and ends on the round 70 boss', () => {
  expect(roundStartTick(d3, 71) - roundStartTick(d3, 1)).toBe(toTicks(63 * 34 + 7 * 70));
  expect(roundStartTick(d3, 1)).toBe(toTicks(15));
  expect(d3.waves.find(w => w.round === 70)).toEqual({ round: 70, type: 'boss', boss: 'jinegaksi7' });
});
```
