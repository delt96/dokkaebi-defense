## A. 바로 고치는 줄

공통: 바뀐 모델 함수는 `packages/client/test`(happy-dom)·`packages/logic/test`에 시험을 더한다. 묶음마다 관련 시험 + `npm run typecheck`가 통과해야 커밋한다. 커밋은 바꾼 파일만 경로로 add한다.

### A1. 사고 방지
1. 되돌릴 수 없는 확인 창(포기 등)은 열릴 때 초점을 '취소'에 둔다. 지금은 `ui/mount.ts:373`이 첫 버튼에 초점을 준다.
2. 지게 후보에서 지금 유닛 자신을 뺀다(`logic/src/econ/jige.ts` `jigeCandidates`). `swapJige`도 같은 유닛으로 바꾸는 요청을 거절한다.
3. 장터: 사유 줄(`gamble-why`)이 생기거나 사라져도 아래 버튼이 움직이지 않게 자리를 미리 잡는다(`ui/gamble.ts:202`).
4. 보관함 '냥' 판매: 3등급 판매처럼 두 번 누르기(`ui/confirm.ts`를 쓴다), 단추를 키운다(`style.css:521`). 끌어 꺼내는 자리와 떨어뜨린다.
5. 대기실 링크 복사: 성공했을 때만 "복사했습니다". 실패하면 주소를 선택할 수 있는 글자 칸으로 보여 준다(`online/app.ts:91`, `online/lobby.ts:45-50`).
6. 닉네임 입력 maxLength를 안내("1~8자")와 맞춘다(`online/entry.ts:49`).

### A2. 깨짐·겹침·작은 동작
1. 지게 행 둘째 줄 문구 잘림(`style.css:619-620`).
2. 도감: 결과가 적을 때 이름 열이 좁아져 역할 태그가 재료 칩과 겹치고 "짚신소환"처럼 붙는 것. 이름 열 최소 폭.
3. 도감: 검색 때 '최근' 줄이 끼어들거나 사라지며 등급 버튼이 밀리는 것(`ui/dex.ts:340`). 자리를 고정하거나 다른 위치로.
4. 도감: 재료 링크로 갔다가 뒤로 오면 '내 판' 필터가 풀리는 것(`ui/models.ts:730,736`). 뒤로 가기 기록에 필터 전부를 담는다.
5. 도감: 목록 재료 칩에도 갖춤/부족(✓/✗, 실선/점선) 표시(`ui/dex.ts:298`). 조합 줄 칩과 같은 규칙.
6. 보관함 20종일 때 2px 가로 넘침(scrollWidth 52 > 50).
7. 대기실 소리 설정 팝업이 바깥 클릭·Esc로 닫히게(`audio/settings-ui.ts`, `audio/settings.css:135`).
8. HUD 게이지와 글자가 붙는 것(`style.css:72` margin-left:-8px).
9. 보관함에서 정보를 연 묶음을 강조한다.
10. 목표 트리: '진영'과 '보관' 구분을 색 말고 글자/모양으로도. 하위 재료가 다 갖춰진 항목에 "지금 만들 수 있음".
11. 솔로 결과 창도 온라인처럼 뒤를 어둡게 덮는다(`style.css:289`).

### A3. 문구·용어
1. HUD: 60/60은 '한계', 넘었을 때만 '무너짐'(`ui/hud.ts:11`). 경계값은 로직의 실제 패배 판정과 맞춘다.
2. 온라인 상단: '역신 첫째 탈 6,632 / 7,480' → '역신(첫째) 체력 6,632 / 7,480'(`online/models.ts:90`). 내 잡귀가 위험(왼쪽 줄과 같은 기준)이면 상단 숫자도 붉게.
3. '포기하고 나가기' → '포기(넋 되기)'. 확인 문구는 그대로 둔다.
4. 설정 '도움말' → 하단 단축키 줄이라는 게 드러나는 이름. '효과 줄이기 끔/켬'처럼 이중 부정으로 읽히는 문구를 정리.
5. 칸 위치 표기를 한 가지로 통일(지게 '진영 20번 칸' / 장터 '4행 5열'). 행·열로 맞춘다. '원가 8'에 단위.
6. 강화: "지금 +20% → 다음 +30%"처럼 누적값과 다음 값을 함께. 창 안에 이번 라운드 저항과 내 물딜·마딜 유닛 수.
7. 장터: 안내 문구 하나로 맞추고(`gamble.ts:155,166`), 처음 열면 첫 상품 확률을 기본으로 띄운다. 돈 도박에 "평균 회수 101%" 한 줄(데이터에서 계산).
8. 솔로·온라인 잡귀 표기 통일(솔로 '우리 고개 잡귀', 온라인 '내 잡귀'). 퀘스트 버튼 문구 통일.
9. 도감 숨은 유닛: "길들이기로 획득"에 어느 적, 몇 라운드부터인지(데이터에 있으면).
10. 넋: 보낸 뒤 "N번에게 5냥을 보냈습니다"를 남기고, 토큰이 쌓이지 않는다는 안내("이번 라운드 안에 보내세요").
11. 첫 판 안내 줄: 판에 유닛이 없을 때 첫 문장이 "유닛을 눌러 선택"이 아니라 소환 안내가 되게(`ui/panels.ts:125`).
12. 온라인 결과의 낯선 말('역신 격파', '잡귀 마지막/최대', '생존·팀 패배')에 짧은 설명(title 말고 화면 글자).

### B1. 다음 조합 한 곳으로 (먼저 할 것)
- 조합 도우미를 "다음 할 일" 한 곳으로: 등급 높은 순, 목표 경로 맨 위, 같은 재료를 나눠 쓰는 조합 표시, '재료 1개 부족' 묶음.
- 보드 '조합 가능' 점: 고른 유닛과 짝이 되는 칸만 밝히기 등 범위를 좁힌다. 색이 아닌 모양으로(6등급 노랑과 겹침).
- 등급 표시 색약 대응(2/5, 4/6등급 구분).
- 왼쪽 패널: 능력 문장을 접고 조합 줄에 자리를 준다.
- Z/X/C 배정 규칙(결과별 고정 또는 최고 등급 우선), '조합 가능한 다음 유닛'으로 가는 키(W 대체 또는 추가).
- 지게 후보 정렬 근거("바꾸면 조합 가능", "목표 재료").
- 끌어 옮길 때 놓을 칸·바뀔 상대 강조, 후반 오라 고리·폭발 효과 정리.

### B2. 창 배치와 큰 화면
- 큰 화면(판 둘레에 여백이 남을 때)에서 장터 서랍·상세·지게·퀘스트·도감·도우미를 판 밖에 띄우는 배치. 배율 1(여백 없음)에서의 대체 배치.
- 장터 서랍이 오른쪽 길·뚝딱을 가리는 문제, 상세·지게·퀘스트가 보드 가운데를 덮는 문제.
- 바깥 화면(첫 화면·대기실·결과)과 판의 배율 기준 통일, 1080p에서의 배율 정책.
- 오른쪽 퀘스트 상자 정리, 하단 카드 스킬 설명을 터치에서도 보이게, 배율 1 글자 크기.
