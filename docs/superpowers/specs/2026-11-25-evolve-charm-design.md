# 진화부적: 길들인 유닛은 진화해야 전용 조합에 쓴다 (2026-11-25)

선행: 3스테이지 아이템 장터(`2026-11-25-item-shop-design.md`, 계획 `docs/superpowers/plans/2026-11-25-item-shop.md`). 진화부적은 그 상점의 다섯째 아이템이다. 아이템 장터가 `claude/firepower-check`에 합쳐진 뒤 만든다.

## 왜

- 지금은 R10 보스 지네각시를 30냥에 길들일 수 있고, 길들이기 전용 조합 5개(`recipes.json`의 `kind: "tame"`)를 20R 전에 막는 것은 `economy.tame.combineFromRound: 20` 하나뿐이다.
- 길들인 유닛 5종은 4등급 히든(factor 0.83~1.16, 일반 4등급 중앙값 0.99)인데, 전용 조합 결과 5종은 6등급 히든(factor 1.0~1.73, 일반 6등급 중앙값 0.97)이라 일반 6등급보다 세다.
- 사용자가 고른 방향: 길들이면 바로 강해지지 않고, 진화를 한 번 거쳐야 쓸 만해진다. 전용 조합 결과는 6등급보다 조금 약하다.

## 정한 것 (사용자)

- 진화부적은 상점(장터 [아이템] 탭)에서 **20라운드부터** 판다. 값은 **묵 1개 + 60냥**.
- **길들이기 전용 조합 5개 모두**, 재료인 길들인 유닛이 진화한 상태여야 한다. `combineFromRound`(20R 잠금)는 없앤다.
- 진화부적은 **아이템 칸을 차지한다**(유닛 하나에 아이템 하나). 다른 부적을 붙이면 진화가 풀린다. 조합·판매·지게로 유닛이 사라지면 함께 사라진다(아이템 규칙 그대로).
- 수치 목표:

  | 단계 | 목표 |
  | --- | --- |
  | 길들인 직후 (진화 전) | 일반 4등급의 약 70% |
  | 진화한 뒤 | 일반 5등급 중앙값 수준 |
  | 전용 조합 결과 (6등급 히든) | 일반 6등급의 약 90% |

## 제가 정한 것 (고칠 수 있음)

- **붙일 수 있는 유닛:** `economy.tame.targets[].unit`에 있는 유닛(길들여 얻는 5종)만. 다른 유닛에 붙이면 새 거절 이유 `notTamed`.
- **한 판 제한:** 없음. 유닛 하나에 하나뿐이라 저절로 제한된다.
- **보관함:** 진화한 유닛도 보관함에 넣으면 부적이 붙은 채 남는다(아이템 규칙 그대로).
- **"수준"을 재는 법:** 유닛 한 기를 빈 판에 놓고, 그 라운드 일반 적 무리를 상대로 30초 동안 낸 피해(스킬·약화 포함, 판 화력 측정 `firepower.ts`와 같은 방식)를 잰다. 길들인 유닛·히든은 스킬이 세서 factor만으로는 맞출 수 없다. 비교 라운드는 길들인 유닛이 쓰이는 때(진화 전·후 21·31R), 히든은 51·59R.
- **진화가 하는 일:** 진화한 유닛은 피해에 배율을 곱한다. 배율은 유닛마다 데이터로 둔다(`tame.targets[].evolvedMult`). 진화 전 너프는 길들인 유닛 5종의 `factor`(필요하면 스킬 배율)를 낮춰서 한다. 히든 6등급은 `factor`·스킬 배율을 낮춰 목표에 맞춘다.

## 만드는 법

### 데이터

- `economy.json` `shop.items`에 다섯째 항목:

  ```json
  { "id": "evolveCharm", "name": "진화부적", "coins": 60, "buckwheat": 1, "fromRound": 20, "effect": { "kind": "evolve" } }
  ```

- `ShopItemDef`에 `buckwheat?: number`, `fromRound?: number`를 더한다. `validate.ts`가 둘 다 `positiveInt`인지, `fromRound`가 판 라운드 안인지 본다.
- `ItemEffect`에 `{ kind: 'evolve' }`를 더한다.
- `tame.targets[]`에 `evolvedMult: number`(측정으로 정함). `combineFromRound`를 지운다.
- 길들인 유닛 5종과 히든 6등급 5종의 `factor`·스킬 배율은 측정으로 정한다.

### 규칙

- `buyItem`: `fromRound`보다 이른 라운드면 새 거절 이유 `itemTooEarly`, 묵이 모자라면 `noBuckwheat`(기존 이유). 성공하면 엽전과 묵이 함께 빠진다.
- `attachItem`: `evolve` 아이템은 길들인 유닛에만 붙는다(`notTamed`).
- 조합: `kind: "tame"` 조합은 재료 중 길들인 유닛이 진화하지 않았으면 새 거절 이유 `notEvolved`. 지금의 `tameLocked`(20R 잠금)는 이것으로 바뀐다. 조합 후보·도우미 목록에는 좁은 줄에 맞게 "진화 필요"를 띄우고, 거절 문구는 "진화부적을 붙여야 합니다"다.
- 피해: 진화한 유닛의 피해(기본 공격과 스킬)에 `evolvedMult`를 곱한다. 곱하는 곳은 `damageBonus`와 같은 자리다.

### 화면 (목업 없이, 아이템 장터 화면을 따른다)

- 아이템 탭 진화부적 줄: 값 "묵 1 · 60냥", 20R 전에는 "20라운드부터".
- 상점 줄 설명은 "무언가를 진화시키는 부적이다."(사용자). 유닛 카드는 진화한 유닛에 "· 진화" 표시만 붙이고 배율 몫 숫자는 감춘다(사용자). 판 위 귀퉁이 글자는 `진`.
- 길들인 유닛의 아이템 줄에서 진화부적 [붙이기]만 다른 유닛에는 보이지 않는다.

### 측정 (`docs/balance/stage3-economy-pass.md`에 새 절)

1. 한 기 피해 측정 스크립트(빈 판에 유닛 하나)로 일반 4·5·6등급 중앙값, 길들인 유닛 5종(진화 전·후), 히든 5종을 잰다.
2. 목표(70% / 5등급 중앙값 / 90%)에 맞게 `factor`·스킬 배율·`evolvedMult`를 정한다.
3. 봇: 길들이기를 하는 봇이 20R 뒤 진화부적을 사서 붙이고 전용 조합을 하게 한다. 어려움 20시드로 클리어·6등급 보유가 바뀌기 전과 어떻게 다른지 본다.

### 시험

- logic: 20R 전 사기 거절(`itemTooEarly`), 묵·엽전 함께 빠짐, 길들인 유닛에만 붙음, 진화 안 한 재료의 전용 조합 거절(`notEvolved`), 다른 부적으로 바꾸면 진화가 풀려 다시 거절, 진화 배율이 피해에 들어감, `combineFromRound` 없는 데이터 검증.
- client: 진화부적 줄 값·잠김 문구, 길들인 유닛에만 [붙이기], 조합 후보 문구, 카드 진화 몫.
- 아이템 없는 판·1·2스테이지 해시는 그대로(골든).

## 하지 않을 것

- 진화를 여러 단계로 두지 않는다(한 번뿐).
- 길들이기 자체(대상·값·확률)는 바꾸지 않는다.
